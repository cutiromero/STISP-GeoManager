# NDVI示例

分类：遥感计算。这是可下载、修改后重新注册的普通算法包，平台业务代码不识别算法名称。

入口为 `main.py` 的 `run(context)`。输入使用 `context.input_path(key)`，参数通过 `context.parameters` 读取，输出写入 `context.output_path(filename)`。只能使用运行环境中已有依赖；运行时没有网络。输出文件名必须符合清单。

将本目录文件连同`selftest/`一起压缩，ZIP根目录包含入口、清单和说明。登记同名identifier后上传，试运行并核对结果后发布。修改实现或清单需增加version。

红光`red`和近红外`nir`参数采用当前影像从1开始的实际波段序号，可由智能体依据真实波段名称、波长或传感器说明选择。两个序号必须不同且处于输入波段范围内；输入含义不足时补充说明。默认序号不能代替不同影像的波段对应判断。

配套小样例包含六个命名波段，红光位于第3波段、近红外位于第5波段。清单允许调整波段参数；核心计算代码、输入校准值和缺测处理保持原实现。
