# 地质图面几何修复

接收带坐标系的 Polygon/MultiPolygon 图层，使用 Shapely/GEOS `make_valid` 的线网法修复自相交和无效环，保留每条属性记录和原坐标系。该方法判断几何有效性；岩性、矿物共生、地层关系等语义由相应知识与专业算法评价。

## 输出与审核

- `repaired.gpkg`：全部要素均得到有效非空面时生成，保留原属性，新增 `repair_row`（从 1 开始的输入顺序）、`repair_status`、`repair_review`。一个要素可以修复成 MultiPolygon，仍对应原来的一条属性记录。
- `repair-log.csv`：每要素的有效性、无效原因、前后几何类型、面数量、面积变化、需审核原因，以及 `repair_row` 对应关系。
- `repair-summary.csv`：输入总数、有效数、修复数、失败数、需审核数、面积变化阈值与输入 SHA256。`needs_review > 0` 表示应先审核；`complete_vector = false` 表示未生成完整修复矢量。
- `repair-audit.zip`：`original-input.gpkg` 是输入文件的逐字节副本；`repair-candidates.gpkg` 保存每个要素的完整修复候选（包括降维后的线或点）；另含逐要素记录和汇总。输入文件本身只读。
- `quality.json`：计算平台读取的质量报告。`status = needs_review` 时暂停自动入库；`metrics` 给出总数、有效数和需审核数，`knowledgeFacts.geometryRepair` 提供后续规则核查事实。

对于无法修复成面的要素，保留原输入与候选，仅输出审核包和记录，不将部分成功要素冒充完整修复结果。对于降维片段，审核包保留完整候选，修复面提取面分量并标记需审核。

面积使用原投影坐标系的轴单位换算为平方米；地理坐标系使用 WGS84 椭球面积。大于半球、跨日界线、未知坐标系或非面输入应先裁剪或整理。投影面积反映所选投影的度量；修复后的有效性与面积变化均需结合实际尺度判断。

无效输入的面积是诊断参考值，`area_before_trustworthy = false`，不代表已知真实地块面积。原面积为零、改变面数量、出现降维片段、无法计算面积或面积变化超过阈值均标记需审核。默认阈值为 5%，可以按任务调整。高程坐标不参与二维面积与拓扑判断。

## 接入

运行 `python backend/manage.py seed_geometry_repair` 登记公共算法草稿。命令可重复执行，并保留已经存在的名称、说明、启停状态与版本。发布前沿计算中心现有试运行流程，使用有效面、自相交面、孔洞、退化面等样本检查日志和面积；真实试运行通过后才发布。
