# 玛纳斯冰川范围提取

输入为已登记的玛纳斯 Sentinel-2 原始影像。四个 Byte 波段按 B2、B3、B4、B8 排列，像元为 10 米，坐标系为 WGS 84 / UTM 45N。计算沿原始网格分块读取有效区。

受管 GPU 运行时加载项目登记的 AGRS DLinkNet34 源码、整体预测权重和归一化配置。256 像元窗口的模型输出按中心区域拼接。归一化统计取自交付的 7 月 29 日训练清单。

- `classification.tif` 与原始影像同网格，类别为 0 非冰川、1 冰川、255 缺测。
- `statistics.csv` 记录有效与缺测像元数量、冰川像元占有效区的比例以及按原始网格计算的面积。
- `quality.json` 记录有效区统计口径、模型和归一化摘要。

计算中心的自检以一幅带缺测像元的四波段小样例核验分类图和统计表。整景试运行使用项目内的 T45TUJ 原始影像，通过正常质量和入库检查交付成果。
