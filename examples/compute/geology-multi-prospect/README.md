# 优先核查远景区分析

正式算子`geology-multi-prospect@2.2.0`，默认收敛尺度。使用修正后岩性、构造、五类矿物及其有效权重、研究区和当前交汇，只输出修正后的远景区、强证据核心、逐区依据与连续支持度热力图。

蚀变、构造和岩性支持分别占45%、40%和15%。强核心保留显式绑定的P-01/P-02/P-03条件，默认要求250米矿物邻域加权类型数至少2、原构造支持、已知基岩及有效观测。外围结合600米矿物邻域、断裂距离衰减及岩性支持；零权重与剔除数据不提供正证据，缺测仍为无观测。

默认50米分析网格，连续支持场按100米Gaussian尺度平滑，直接提取等值线边界。一个自然连通支持域分配一个编号，相交或接触的范围先合并；真实间断和孔洞保留。面积较大的连通支持带整体保留并记录提示，数量上限只用于排序选区。默认最小区域1平方公里、最小强核心0.05平方公里，收敛尺度最多8区。

`prospect_grid_resolution_m`独立于检查阶段的网格设置，确保普通逻辑推理使用已验证的50米远景区分析网格。所有可配置参数及范围位于`main.py`顶部和清单中，尺度参数位于`prospect_fields.py`顶部。

面积、核心面积按实际几何测量，支持度按分析格网近似。逐区证据采用平台现有修正后协议，包含实际矿物、构造、交汇、岩性、核心和外围的测量与知识版本。质量报告成功时为`passed`，并保留真实空结果。热力图的红、黄、蓝表示高、中、低综合证据支持度，未用实际矿点标定，不表示有矿概率。

通过共享`geology-multi-core/build.py`构建独立算法ZIP。除现有地理计算依赖外，等值线提取需要`contourpy`；正式服务器已验证具备该依赖。原始登记数据保持不变，历史任务继续使用其冻结的算法版本。
