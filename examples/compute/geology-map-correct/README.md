# 地质成果受约束修正 1.0.1

沿用检查输入，增加平台保存的获批`changes`表。算法基于当前三份输入重新计算全部问题，逐项核对issue_id、kind、图斑、原值、目标、规则、证据和内容校验和。提交的空间范围如有提供也须匹配实际问题。

所有获批操作核对通过后才产生输出。fill_gap将当次计算得到的内部空洞填回唯一宿主，保持原图斑ID；set_age仅更新时代字段。其他分类映射、正常图斑和边界保持。实际地图几何差异须等于获批填补范围。

输出修正后地质图、修改范围GPKG、带知识来源的执行CSV与按class计算的前后面积表，质量报告记录实际修改数量、填补面积和剩余问题。模型应读取真实结果并继续复核。算法的批准表需由平台审核接口产生；该算法不直接替代平台的人机批准权限。
