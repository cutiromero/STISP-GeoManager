# 互花米草三季节 RF 解译

按03月、08月、12月及固定16波段顺序组合48个特征。平台先固定研究区原始WGS84窗口，算子输出分类GeoTIFF、目标概率、椭球面积统计，以及用于对比的08月真彩色预览。

分类沿用交付模型的predict：0为有效非目标区，1为互花米草，255为无效区；概率通过classes_定位目标类别，缺测使用独立NoData。全部48特征共同有效的像元参与统计，斑块使用8连通口径。预览分位拉伸不改变模型输入。

权重位置、摘要、解释器与资源预算来自受控运行配置，模型不随算子包上传。实际scikit-learn版本、原始输入摘要、模型摘要和研究区参数保存在任务记录中。
