# 地层时代属性受约束纠偏 1.0.2

沿用检查的 `features/surveys/rules`，增加 `changes` 修改计划。重新独立检查每项原值、新值、内容校验和、规则、引用与适用地区；每轮最多修改10个对象，只允许 `geologic_age`。所有项通过后输出新GPKG、实际修改记录和统计。

岩性类别、其余属性与全部几何保持。地图点击字段保留修改前后值及经验证的引用原因，模型的说明单列为 `model_reason`。结果应再调用检查算法。对真实副本中的演示录入错误验证属性一致性；结果与人工精修岩性相似度应独立报告，不把属性修复称为岩性精度提升。

`region/geologic_age`为演示准备依据辞书新增，并非师弟实测字段；地区适用条件尚未独立野外核实。编辑验证是对3项预置时代录入错误的恢复。算法只使用现有平台SDK接口，计算任务状态由平台显示。
