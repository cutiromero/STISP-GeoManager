# 冰川同样区变化统计

在 3 米北向上 UTM 原生格网上，对编码 0（背景）、1（洁净冰川）、2（表碛冰川）进行面积和转移统计，255 为缺测。对于两期分类，格网必须完全一致；净变化和 3×3 转移矩阵仅在两期共同有效范围内计算。

首期可不绑定历史分类或时相资料，输出本期面积，日期和差值留空。双期必须一并绑定经人工核验的单行 UTF-8 CSV，列为 `current_date,baseline_date,current_source,baseline_source,comparable`。日期采用观测日（YYYY-MM-DD），不能用上传日期代替。来源列记录实际影像与可追溯的日期依据；核对同样区、季节、云雪、几何、权重和处理规约后，`comparable` 填 `yes`。这张表记录人工确认，不能替代观测质量复查。若仅登记本期日期，后三列中与基线相关的内容及 `comparable` 留空，`current_source` 仍需填写。

算子输出面积、转移矩阵、时相与覆盖三张具名表。面积以原生 UTM 平面像元面积计算；工程分类不等同于经复核的冰川变化。
