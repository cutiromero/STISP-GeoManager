# 冰川同样区变化统计

在 3 米北向上 UTM 原生格网上，对编码 0（背景）、1（洁净冰川）、2（表碛冰川）进行面积与转移统计，255 为缺测。双期格网必须完全一致；只在共同有效区内统计差值及 3×3 有向转移矩阵。

在冰川业务流中，用户只选本期影像。主 Agent 调用预检，平台从已有资料时相与分类入库记录选取同项目、同观测系列、同原生格网、同一 b15 算子版本的最近前期；比较日期来自双方原始影像登记的观测日。不使用文件名、上传日期、未通过质量门禁或试跑的分类。缺少登记日期、同系列历史或共同有效覆盖时，仅给出本期统计并记录原因，差值为空。

面积为原生 UTM 的投影像元面积。分类差异不等同于冰川物理变化；复核应考虑云雪、季节、传感器和几何条件。
