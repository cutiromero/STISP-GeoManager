# 获批操作执行

使用 `../geology-multi-core/build.py` 构建独立 ZIP。不要只打包本目录，worker 必须包含共享核心。

算子版本1.2.0：完整校验批准依据后逐矿物输出修正、权重与变更栅格；分块及资源验收方式见共享核心README。

规则参数来自本场景明确绑定的试用知识及版本；输出保留当次测量、知识引用与算法证据。获批执行必须精确匹配对象、范围、规则版本与输入快照。

所有输出写入当前任务目录；支持空结果。计算使用米制投影，显示沿平台既有坐标转换。

平台SDK提供与当前任务文件身份绑定的已核验证据标识时，复用像元、掩膜及权重标识，避免重复全幅扫描；独立调用仍计算实际标识。两条路径的科学输入快照、规则处置与输出语义一致。
