# MHGDAL 工具适配

由用户提供的 MHGDALBasicAlgorithms C++ 导出接口适配为平台计算包。算法在独立计算任务进程执行，基于 GDAL、OGR、NumPy 和 Shapely；不会导入到 Django 请求进程。

输入从当前项目的数据资源选择；空间数据须带坐标系。矢量输出为单图层 GeoPackage，影像输出为 GeoTIFF。原始数据保持不变。目录批处理改为单任务显式输入；波段合并一次最多8幅影像，可分批合并。范围参考目前使用影像，矢量范围可通过显式坐标输入。

原实现迁移时修正了空几何、数值溢出和越界行为。简化采用显式容差与拓扑保持，不沿用未标定的1–10级参数；拓扑关系按共享外环顶点定义。光谱表标准化为CSV：首列wavelength，后续每列为一个类别的参考光谱，一行对应一个影像波段。分类结果是与全部参考光谱比较后选取最小角度，低于对应阈值才赋类。无有效光谱为0。

格式转换、批量裁剪与岩心展开输出ZIP，只供下载，解压后可按平台支持的格式导入。ZIP同时包含伴随文件，避免ENVI头文件、地理参考信息丢失。岩心展开采用局部坐标，不直接入地理资源库。

训练与测试原函数均为空实现，因此登记为禁用占位，不生成可执行版本。MHAlgTest为旧界面参数演示，GetFunc*为界面说明接口，注释掉的MHShpRectConv没有实现，均不作为计算算法发布。

运行环境需要GDAL Python绑定；版本发布前必须完成真实试运行和结果验证。合成样例用于验证实现，不代表已完成真实岩心数据的科学精度评价。
