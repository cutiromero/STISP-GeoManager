# 地层时代属性一致性检查 1.0.2

面向有稳定类别编号和地层标识的真实地图。输入地层与地区决定适用辞书条件；构造距离和蚀变命中只构成真实空间上下文，不承担时代测定。小图斑面积仅作筛查提示。

`features` 是 `data` 图层，含 `feature_id/class/formation/region/geologic_age`；`surveys` 是候选空间上下文CSV，明确为 `spatial_context`；`rules` 是带条目定位、条件、例外与WGS84地区范围的 `dictionary_definition` 规则CSV。候选具备来源和几何一致的上下文，且同一条件下时代唯一时，产生 `repairable`。缺时代、冲突或缺上下文时保留复核。

输出问题表、问题面与质量统计。可以在纠偏后再次运行。人工精修图、未设错副本、设错清单只用于独立验收，均不属于输入。

平台存储的WGS84地图按明确的`working_epsg`（默认32646）转入米制投影做面积核对和内容校验；输入坐标及几何在输出中逐字节保留。检查与编辑使用相同工作投影。

本轮副本中的`region/geologic_age`是演示准备新增字段。时代按辞书补录，地区由图件地层标识和辞书分布暂作适用条件，未独立野外核实。3项错误由演示明确预置，不是师弟原图实测时代错误；本轮验证地层名与时代属性一致性。

运行严格使用现有平台SDK的`input_path/output_path/parameters`接口，任务阶段进度由平台显示。
