# NDVI变化与候选区提取

入口 `run(context)` 通过平台提供的输入/输出路径工作，运行时使用已有地理计算环境。该目录可由平台模板机制打包；注册、试运行和发布由管理员完成。

`early_ndvi`、`late_ndvi` 为单波段、[-1,1]尺度的两期NDVI；`valid_mask` 为一个共同有效波段，或前/后期两个有效波段。掩膜中有限正值表示有效，0、NoData和非有限值表示无效。三者的CRS、仿射变换与宽高必须完全相同，CRS须为米制投影。

参数 `early_date`、`late_date` 为 YYYY-MM-DD，后期晚于前期。比较资料应为同季节、可比较定标，云和阴影判别由提供的有效掩膜表达；算法记录实际日期、掩膜及输入校验和。`decline_threshold` 默认 -0.15，是本次可调演示阈值。比较时允许1e-7的float32舍入误差，两步算子的判断口径一致。

仅在两期都非NoData、有限、NDVI在[-1,1]且掩膜有效的位置计算 `后期−前期`，其余位置写入 -9999。超范围的观测被排除并在质量报告中标记需审核；全部无效时也保留输出并标记需审核。

- `change.tif` 保留原网格，float32，NoData=-9999；标签保存日期和输入校验和，供下一算子匹配观测时段。
- `candidates.gpkg` 的 `candidates` 图层按下降像元的四邻接聚合，包含像元数、投影面积、平均/最低变化及日期；没有候选时仍产生空面图层。
- `statistics.csv` 为一行可读取统计，包含总/有效/无效像元、超范围数、有效及下降面积、下降占有效面积比例和平均差值。
- `quality.json` 沿用平台质量协议；`passed` 表示输入检查与计算成立。报告中的知识事实绑定日期、掩膜和实际输入。

面积采用仿射变换行列式的绝对值，即输入投影的平面平方米。两期下降是植被变化线索，原因与持续退化的判断结合背景、观测和更长时间资料；绿光—近红外NDWI用于辅助水体判读，根区土壤水分另需相应观测。
