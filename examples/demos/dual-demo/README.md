# 两项目模拟资料生成

在仓库根目录点载 `activate-local.ps1`，使用现成项目环境执行：

```powershell
. ./activate-local.ps1
& $python examples/demos/dual-demo/generate_samples.py <科研数据目录下的新样例目录>
```

生成器只写给定目录，不写平台数据库、不登记资源、不启动服务。默认固定种子20261010；已有样例目录会保留，请选择新目录。代码和文本由Git记录，生成的大型资料放科研数据目录。

## 可注册输入

- `ecology/early.tif`、`late.tif`：128×128、30米、EPSG32645，两波段float32反射率，1=红光，2=近红外，尺度1、偏移0。日期为2025-09-15、2026-09-15；先用已注册NDVI分别计算，再交变化算子。
- `ecology/mask.tif`：2波段，分别表达两期有效性；1有效，0无效，比较用交集。该掩膜是模拟质量设定。
- `ecology/zones.gpkg`：`data` 图层，`zone_id=stable/decline/missing/cropland`。每区64×64个像元；后期稳定区NDVI0.64，下降区3277/4096像元NDVI0.35，其余0.64；缺资料区NDVI0.30、共同有效819/4096；农田区NDVI0.20。前期均为0.65。
- `ecology/context-initial.csv`：四区模拟背景、明确的农田背景，以及下降区期间缺水记录（confidence=0.9,value=1）。
- `ecology/context-updated.csv`：初期全部记录加农田区2026-09-14收获证据（confidence=0.95,value=1），只新增这一项。表头兼容调查优先级算法。
- `geology/initial.gpkg`：`data` 图层，6个EPSG32645模拟面，含稳定ID、接触类型、岩性及模拟说明；4个内容正确（其中1个低置信异值调查待核实）、1个无效尖刺几何、1个有明确调查支持的接触类型错误。
- `geology/surveys.csv`：与工作投影EPSG32645一致的调查x/y，F06高置信记录支持整合→断层，F04低置信异值记录保留待复核。
- `geology/rules.csv`：允许contact_type在整合/断层间按调查一致性规则执行set_attribute，最低可信度0.8。

上述所有数据来源性质为模拟，CSV另有nature和note列。`manifest.json`记录角色、日期、投影、种子、波段、规则性质与各文件校验和，作为导入和重复演示说明。

## 验收资料隔离

`acceptance-isolated/geology-reference.gpkg` 与 `geology-errors.csv` 只用于独立验收，保持在该目录，导入时仅选择 `ecology/`、`geology/` 中明确列出的输入。参考图修正无效面及明确属性错误；低置信对象保留原值。无效尖刺由make_valid产生面及线片段，几何修复质量报告会要求审核，审核资料保留线片段后再确认面图。

## 核对预期

采用两个生态算法默认演示参数，初期农田调查排名第1、下降区第2；新增收获证据后下降区第1、农田第2，稳定区后排。缺资料区覆盖率约20%，单列“优先补资料”。下降区的缺水记录始终存在，更新只改变农田收获解释。排名由实际NDVI、掩膜、面积和观测计算产生。

地质检查应识别无效几何、明确属性矛盾和证据不足项。先几何修复并审核，再根据当前实际资源重跑检查，使用这次的input_checksum提出有限属性修改；编辑后再检查，F06为断层，F04仍为整合且保留待复核提示，正确对象的岩性与几何保留。

演示解释使用“植被变化线索”和“调查优先区”。两期变化的原因与长期生态状态结合相应观测；绿光—近红外NDWI辅助水体判读，根区土壤水分使用相应资料。
