# 遥感监测

按已选业务流确定研究区、时期、观测来源和交付图件。查看资料时间、空间覆盖、格网与字段，按算子清单匹配本次输入。用户给出多个研究区时，可分别运行并对照同一统计口径。

- 土地覆盖解译关注实际分类体系、影像有效区域、分类图和各类面积。
- 互花米草判读使用同年三季影像，核对波段、共同有效区域、识别概率、斑块和面积统计。
- 历史野火观测核对观测期、火点或辐射功率字段与单位，再按时期绘图和比较时序。

资料覆盖有缺口时，按用户目标选择共同覆盖、分期对照或补充观测。用实际图件和统计表组织结论，给出研究区、时期、主要数量与结果链接。
