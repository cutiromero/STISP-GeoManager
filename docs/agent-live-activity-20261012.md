# 智能体与科研工作流的运行呈现

智能体在处理任务时显示活动光标和轻蓝色流光，帮助用户区分等待、分析、计算、保存及需要回答的问题。当前会话和科研工作流入口提示实际活动状态，侧边工作流显示当前步骤。

普通深度思考沿用现有模型增量与服务端完整累计思考文本，按实际换行显示，生成中的末尾标出光标。事件游标承担新事件和工具状态更新，完整思考正文取自本次运行的thinkingText。

科研工作流的模型判断经现有资料、引用和算法授权校验后保存。页面按发现、当前判断、算法与参数依据、实际结果及下一步呈现分析说明。模型请求尚未形成判断时，页面显示相应真实状态；计算阶段沿用真实任务阶段及进度。

等待用户回答或审核时，页面明确显示所需操作，活动动画停止；完成、失败、取消及中断保留相应状态。重新打开页面时直接显示已经保存的说明，新增内容采用轻微渐入。用户回看前文时保留其阅读位置，跟随最新内容时再滚动。

界面沿用平台蓝色风格。减少动态效果模式显示静态状态及完整内容，手机布局保持可读。

本次改变为前端呈现；调用范围、模型与计算预算、质量审核、持久化记录、数据库和知识服务保持原有契约。

使用入口：智能体的模型对话、数据智能体，以及输入框中的科研工作流。运行时侧边“当前任务”提示阶段，对话末尾显示活动状态；开启深度思考后，普通模型的实际思考内容可展开查看。科研工作流的“分析说明与决策依据”随已保存的判断更新。

本机验证：五组 Chrome 浏览器专项共62项通过，减少动态效果上下文5项通过；类型、改动文件格式与静态检查、生产构建通过。覆盖长思考完整保留、运行到等待及完成的状态变化、历史恢复、新内容渐入、用户回看、手机宽度及权限撤销后的任务清理。服务器与真实模型验证的实际结果随冻结发布回执独立保存。
