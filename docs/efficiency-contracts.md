# 重复工作治理与效率回归

相同输入、相同数据版本与相同授权范围内的工作应有统一执行入口。复用只减少重复读取和纯计算，不替代权限、数据版本、执行授权或结果质量检查。

## 门禁触发范围

实际改变以下路径的读取或执行行为时，运行完整 `make check-efficiency`。仅改文案、布局、注释等不改变这些行为的任务，按 `AGENTS.md` 的小改动验证执行；文件名匹配不能代替行为判断。

| 路径或行为 | 重点边界 |
| --- | --- |
| `frontend/src/api/`、资源概况、可视化统计、显示查询和 hooks | 共享在途入口、完整键、响应副本、最后使用者取消、写入/上传失效 |
| `backend/apps/catalog/`、`backend/apps/raster/services/`、显示几何与瓦片缓存 | 并发冷启动存储锁、完整版本和参数、缓存命中不占槽、失败释放与重试 |
| `backend/apps/compute/packages.py`、`input_versions.py`、`result_reads.py`、`backend/apps/core/file_evidence.py` | 文件身份/签名/依赖、摘要、CSV 分页、栅格统计、像元和掩膜一致性、暖缓存撤权 |
| `backend/apps/business_flows/` 的输入适配/准备与 runtime、算子准备和调度 | 共用版本与结果读取入口，不按案例或算法白名单复用；独立科学任务不合并 |
| `backend/apps/agent/` 的历史、上下文、`run_activity`、`run_stream` 及前端智能体/业务流轮询 | 一次响应批量事件、精确来源列表复用、真实流增量、游标恢复、实时停止/撤权、有界槽与轮询回退 |
| 以上路径的权限隔离、登录切换、取消、缓存失效、重试、存储锁及公共构建读取 | 不缓存授权、不让旧请求污染新身份；共享结果不扩大项目或 owner_only 范围 |

优化前先记录真实调用链、操作次数及输入版本。新增昂贵调用同时提供适用的次数、版本/项目隔离、撤权、取消、失败重试及失效回归，不只断言最终成功。文件校验不能改变科学摘要、跳过版本检查或扩大输入范围；栅格、几何和属性优化同时验证结果一致及原始文件未修改。

快速验证脚本按顶部路径表选择相关效率用例；这不代表完整门禁已运行。新增读取入口须维护映射，且通过其他数据/任务、身份变化、缓存损坏及暖缓存撤权回归。浏览器使用 `frontend/scripts/run-browser-check.mjs` 管理源码一致的 ASCII 镜像，不删除 mock 或放宽断言；正式 `build:verify` 保留 `/static/` 基址。

## 共享边界

| 工作 | 统一入口 | 复用范围 | 失效条件 |
| --- | --- | --- | --- |
| 资源概况、可视化统计、地图显示查询 | `api/client.ts`、`ReadFlights` | 当前页面相同键的在途请求 | 完成、失败、登录/项目/资源修订变化、写入或上传边界 |
| 瓦片就绪状态 | `hasCurrentVectorPreview` | 当前登录与项目中刚核对的描述符或未就绪状态，最长30秒 | 到期、写入、来源变化；从浏览器存储还原的描述符重新核对 |
| 无属性筛选的显示几何 | `cached_display_query` | 版本匹配的持久结果；进程间锁合并冷启动 | 资源修订、存储图层、完整查询参数或算法版本变化 |
| 输入版本准备 | `version_lock`、`storage_lock` | 同一资源版本的独立输入快照 | 源身份、内容、依赖或授权变化 |
| 同步操作内的文件摘要 | `checksum_scope` | 文件描述符和路径身份均未变化的同一同步操作 | 操作结束、异常、替换、尺寸/时间/模式变化 |
| 智能体进度与历史事件 | `load_run_activity` | 当前HTTP响应内一次批量读取 | 每次请求重新读取；不缓存权限或进度 |
| 智能体上下文来源 | `reusable_context_sources`、`check_context_sources` | 同次构建使用已读取并核对的精确来源列表 | 下一次生成、恢复或实时检查重新读取并授权 |
| 受管文件完整性 | `packages.checksum`、`core.file_evidence` | TOML数据根目录内同一文件身份的带签名摘要 | 路径、设备、inode、大小、mtime、ctime或模式改变；签名失效；显式强制校验 |
| 计算结果表分页、栅格统计 | `compute.result_reads` | 同一实际文件版本、读取器版本和依赖的私有索引/统计 | 文件或掩膜等依赖变化；缓存损坏、过期或清理 |
| 智能体实时输出 | `run_stream`、`watchAgentRun` | 当前本人项目运行的快照和真实游标增量 | 断线重连、换项目/登录/会话或取消时关闭；实时撤权停止读取 |

前端完整响应不在完成后继续缓存。多个使用者分别取得数据副本；取消一个使用者只取消其等待，最后一个使用者离开才中止底层请求。共享键包含登录代次、项目、资源编号和修订、语言、读取种类及完整参数。读取开始时固定参数和语言，响应返回时再次核对登录与项目归属。显式精确查询、导出和写操作不因显示请求合并而被重放。

瓦片状态复用只避免立即重复核对已知就绪情况，不是权限凭据。实际查询和瓦片请求仍由服务器鉴权。正、负状态均有时限，离线准备完成后不会因永久缓存“未就绪”而始终无法升级。

显示几何在缓存未命中时，经固定数量的存储锁协调HTTP线程、其他Web进程及后台预热。相同缓存写入目标互斥，不同版本分别核验，旧计算不能在新计算之后覆盖当前版本。锁文件数量有界；等待超时沿用503和Retry-After。缓存命中及等待方复用不占执行槽，真正计算仍服从原并发上限。属性筛选和精确业务查询保持各自原语义。

每个请求都独立检查当前用户、项目和资源访问权。不得把准入结果存入共享计算或持久缓存。失败不缓存为成功；进程退出自动释放存储锁，后续请求可以重试。

智能体序列化单次运行或整段会话时，用一次事件查询读取思考和用量，并在数据库内选择各运行最新的参数和回答预览。不得逐轮重复查询事件，也不得把历史累计预览全部取出后再丢弃。增量事件游标独立保留，完整思考、用量统计和终态表现保持一致。批量读取不代替每轮资料和知识的权限检查；下一次轮询必须看到新增事件。

实时连接只在初次、工具结果和运行状态边界构造完整快照；思考与正文帧仅传新事件，不能每帧重读全部思考、正文或证据并重复序列化。正文使用增量事件及64Ki字符检查点，避免累计正文随每个token反复落盘。前端真实流正常时不同时轮询同一运行，旧服务或通道满额才回退；换项目/会话及卸载中止底层读取，事件游标缺口通过新快照恢复，不重新提交任务。共享流槽有界，关闭尚未迭代的响应也必须释放槽位。

连接连续15秒未收到任何数据（包括服务心跳）时关闭底层读取，使用现有读取接口恢复最新进度后再尝试实时连接。请求本身的传输中断不会结束仍活跃的任务监视；页面取消、换项目或登录变化仍由调用方取消和现有授权边界控制。恢复不重新提交或批准业务任务，正常心跳期间不增加并行轮询。

实时上下文核对直接取精确来源列表并检查数量，避免先COUNT再读取；构建上下文时沿用该次核对所得的来源编号，不能再次查询另一份来源列表。此复用只在当前同步操作内生效，不跨模型请求缓存访问决策。历史资料被撤权、来源被删除或当前选择改变时，下一次实时核对仍拒绝继续使用。

仅存在结构化知识或文档引用时才解析知识范围。空依据和仅有数据资源的检查不应触发知识路由及其历史主题查询；真实知识引用仍逐次核对范围、版本和访问权。

## 所有任务共用的数据读取规则

完整性证明属于文件版本，不属于某个任务、算子、资料名称或固定编号。所有调用公共`checksum`的计算、智能体、专业工作流、预览和入库入口都采用同一机制：每次读取当前文件身份，未变化时复用经过服务密钥认证的摘要；变化、文件替换、恢复mtime后的改写或签名失效时重新完整读取。`force=True`显式要求重算。TOML受管数据根目录外的文件与符号链接不采用持久证明。证明不缓存权限，也不合并独立科学任务的算子执行。

证明通过原子替换发布，4096个固定槽位限制文件数量，256个进程间锁合并并发首次校验；槽位冲突只淘汰旧证明，不改变结果。缓存存储不可写或等待锁超时后执行严格完整校验，不返回未经核实的旧摘要。同步操作内的原有摘要作用域继续生效。

结果表首次读取时按真实CSV记录创建稀疏定位索引，每256行记录一次文本定位点，保存实际字段和总行数；兼容BOM、中文、引号及单元格换行。后续分页最多跳过255条记录再读取目标页，不重新扫描整表计数，也不复制整表内容到另一个数据库。智能体结果读取和平台表格预览共用此入口。栅格近似统计按相同机制只计算一次，`.aux.xml`、`.msk`、`.ovr`变化使其失效，保持原统计口径。

索引与统计绑定原文件摘要、完整身份、依赖和读取器版本，缓存清单和索引身份同样经过签名核对，读前、读后再次核对源身份。部分构建不发布；下次可重建。保留时间和容量采用现有计算配置，由后台统一清理；正在读取的索引不会被清理。原始输入、输出和科学验证不因缓存被改写。

每次读取仍核对当前项目、用户、真实任务绑定、输入访问权、执行选择、成功状态和过期状态。暖缓存不允许绕过撤权、取消、文件变化或跨任务/跨项目约束。新读取功能须接入上述公共入口，不能在场景代码中重新实现文件哈希、CSV全表计数或栅格统计。

## 科学结果一致性

栅格输入摘要保持原来的“所有有效像元值字节，再接所有掩膜字节”顺序。一次分块读取同时取得值和掩膜，掩膜使用最多8MiB内存的临时流顺序保存，超出后使用自动清理的私有临时文件；值摘要完成后拼接同一批掩膜字节，不重新读取原像元，也不让NoData派生掩膜触发第二遍数据读取。正常有效值、NoData和独立掩膜均须与原摘要完全一致，不能修改摘要协议或重建科学算子来掩盖差异。

复用已存在的输入版本时仍重新授权；算法取得独立inode的工作文件。几何量化、PNG/XYZ、MVT或缓存资料不能代替精确计算输入。原始文件、已冻结算法版本和任务绑定保持独立可核对。

独立科学任务和用户明确要求的重算不合并，不跨任务用旧算子输出冒充新执行。随机算法、规则修订、不同参数、不同输入版本或不同授权范围应分别处理。

## 地表覆盖计算与大屏读取

GPU算子的模型资产沿用文件身份和内容摘要凭据；稳定权重只校验一次内容，变化后重新读取并拒绝与登记摘要不一致的资产。原始RGB的网格合同复用同次元信息读取；普通算子不能借用GPU的大输入预算。合成计数、图例和分类入库共用已有结果检查，产品列表只读取有界元信息。

阶段缓存限定当前任务与显式重试，身份覆盖输入、权重、代码、处理参数和环境；复用时核对掩膜摘要。清理仅删除过期非活动缓存，活动重试保护其父任务缓存。入库恢复保留成功科学任务，暂停和停止阻断后续自动入库。

大屏任务卡与抽屉共享一次当前任务读取；页面隐藏、等待人工和终态停止计时，完成时只刷新一次成果。查看类别和切换地图对比不提交科学计算。专项回归见`test_gpu_landcover_runtime.py`、`test_landcover_outputs.py`、`test_landcover_monitoring.py`及`LandcoverDashboard.efficiency.browser.test.tsx`。

## 必过检查

在项目既有运行环境中执行：

```bash
make check-efficiency
```

也可显式指定同一运行环境：

```bash
make check-efficiency EFFICIENCY_PYTHON=/path/to/project/python
```

该入口执行后端`efficiency`标记测试、前端在途共享单元测试和真实浏览器SDK回归。`build:verify`另外包含快速前端效率检查。触及“门禁触发范围”所列行为的提交与发布必须运行上述完整入口，并把门禁结果及实际数据验收结果放入回执。

同轮快速检查使用 `make verify-fast VERIFY_FAST_ARGS=--separate-efficiency`，将后端效率用例统一交给本入口执行一次；该参数不会执行或替代完整效率门禁。分阶段记录通过结果；仅浏览器等某个阶段因环境失败时，只重跑该阶段，已通过且未受后续改动影响的阶段继续有效。

回归断言覆盖：

- 相同并发冷请求只实际计算一次，缓存命中不占执行槽。
- 版本改变分别计算，旧版本不能覆盖新版本。
- 文件锁跨进程互斥，异常和进程退出后可重试。
- 多组件读取只发一个请求，结果副本互不污染。
- 单个取消不影响其他使用者，全体取消终止传输，随后可立即重试。
- 登录代次、项目、版本和参数不同不合并；写入后不复用旧的在途请求。
- 来源数量从1增加到50时，授权查询次数不逐对象线性增长；撤权仍立即拒绝。
- 文件修改、替换和中途变化使旧摘要失效。
- 栅格像元解码次数减少，旧、新科学摘要及原始文件字节完全一致。
- 智能体完整进度只查一次事件；30轮会话同样只查一次事件，轮询另保留增量游标查询。
- 智能体只提取当前参数和预览，下一次轮询读取新事件；已完成运行不再展示旧预览，思考时长和用量不丢失。
- 上下文来源只读取一次；精确祖先编号、撤权和来源删除检查保持有效。

新增昂贵调用应给出调用位置、输入身份、执行所有者、复用范围和失效条件，并提供相应的操作次数回归。不得只验证最终成功，或把减少权限与质量检查当作性能优化。新的后台线程、HTTP客户端和缓存层应复用统一入口，避免各自再实现一套。

## 业务流准入与成果收集

通用业务流、专业逻辑推理和直接计算共用`compute.data.candidate`及`input_metadata.candidate_metadata`。表格、矢量元信息以资源修订、文件完整身份、SQLite WAL/journal和读取选项绑定签名凭据；4096个固定槽位及256个进程间锁限制存储和合并冷读取。文件变化、保留mtime的改写、修订变化或凭据签名失效均重读。缓存错误回到严格读取，不保存访问决定或失败结果。栅格保持有界头读取，实际像元与掩膜校验继续由输入版本服务承担。

同一准入中重复端口引用同一资料只解析、鉴权一次；下一次准入重新授权。未变化资料的预检、提交及再次预检只执行一次元信息读取，保留全表字段类型推断。业务流预检和成功复用另绑定核心版本、清单及输入物理身份；不能只比较资料编号。成功复用和节点交付核对成果现状，不产生新的计算任务或重置额度。

`compute_result_tools.read_task_outputs`统一收集全部非归档输出，任务及其输入在读取前后各授权一次，授权次数不随输出数增长；每个输出仍检查状态、过期和校验和。组合工具观察容量不足时使用完整成果引用，不丢弃后部输出。覆盖入口为`test_compute_input_metadata.py`和`test_business_flow_execution_consistency.py`，包含读取次数、并发合并、输入变化、缓存损坏、撤权、成果失效及只修改分析时不重算的回归。

## 会话历史与候选资料的按需读取

会话详情在一次同步响应内读取策略、完整来源集合、活动事件和附件元数据。明确记录的来源编号仍限制在同一会话、较早且成功的轮次；旧记录没有来源编号时仍检查此前成功历史，包括当前显示的100轮之外。来源去重后分别鉴权，不能因为某一轮已显示而省略更早引用的来源；下一次请求重新读取策略和检查来源。完整来源检查不读取无关回答正文，也不将已验证编号跨请求保存。

30轮空证据历史的操作次数回归：普通对话策略读取从31次降为2次；科研智能体来源检查从465次降为30次，策略从31次降为2次，数据库查询从385次降为37次。附件元数据按会话一次读取，避免各轮重复查询。该数字衡量这组隔离样本的操作次数，不代表模型生成耗时或所有业务资料的端到端耗时。

普通智能体自动选择资料时不加载手选候选目录。用户展开数据选择并切换到手动后才读取，同一工作区在途请求合并；成功结果仅用于当前选择界面，失败可重试，离开和权限变化中止请求。服务器提交任务时仍实时验证每个已选编号和访问权限。

系统数据搜索一次请求仅构造一次业务可发现集合。普通入库判断在外层已经受限的资料集合上执行，不在每个入库子查询内重复展开同一项目、ACL与内部资料排除条件；子查询排除尚未入库记录的空资源编号，避免NOT IN中的NULL误隐藏原始资料。专业终端成果仍使用受限集合，以批量字段投影核对阶段、任务、owner、项目、manifest、输出编号及摘要，不实例化未展示的关联模型。目录来自完整可发现集合，计数与分页复用同一关键词及目录限制，空结果或超出末页不读取页面资料。隔离样本含1000条原始资料、100条已核实终端成果和1条基础资料时，包含HTTP权限中间件的单次搜索最多48条SQL，其中涉及资料表的查询最多6条；该上界不随页面内20条资料逐项增加。通用资料选择返回50条时，涉及资料表的查询最多3条。前端连续输入以280毫秒防抖合并，组合输入结束才提交关键词；中止后的成功、错误与结束回调均不能改变新搜索。对应回归为`test_workflow_catalog_search.py`、`resourceSearch.efficiency.test.tsx`及两处候选搜索浏览器测试。
