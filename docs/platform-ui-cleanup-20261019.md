# 界面与数据整理

## 页面变化

地理工作台数据操作使用“信息”“加载”，专题使用“编辑”。空间查询面板以内容自然高度排列，按面板宽度调整分栏，超出可用高度时在面板内滚动。地图查询语义保持。

智能体入口使用“快速对话”“科研智能体”，开关使用“逻辑推理”。输入栏提供上传文档以及算法、数据、知识库入口；模型、分析方案和联网设置集中到思考强度设置内。MH-workflow使用当前对话模型，新建场景依照服务端返回的项目编号筛选；历史已保存场景可恢复。资料选择显示数据目录实际名称。

“按名称匹配资料”仅在一个输入角色存在唯一名称匹配候选时填写建议值，供用户核对，既不调用模型，也不自动启动计算。手动选择资料可完成同样操作。

登录封面沿用数字地球素材，采用淡蓝色标识与简洁登录区；移除数据标签、统计卡、服务状态及持续特效、背景轮换和无展示用途的概览请求。

## 地理数据洞察

优先选择地图点击要素所在图层，其次选中图层，再回退到左侧选中的目录数据。概览请求该对象来源资源的后端摘要，通常是资源整体统计；要素页展示当前点击对象。因此并非全部目录资源或全部图层的合计，筛选图层的概览也不必等于当前可见范围。

## 数据整理口径

业务数据和代码分开管理。整理先对同项目的结果核对算法版本、参数、输入校验和、输出类型及字节校验和；只有完全相同的结果列为重复。不同输入、参数或证据版本继续保留。清理复用既有影响预览、确认令牌与历史删除服务，活动依赖、有效成果与工程引用继续保护。

整理前保留独立备份，记录每项保留/删除理由及名称旧新值。目录名称、关联图层与入库名称保持一致；原始资料、代码、空间字段和历史引用身份独立保留。候选演练、正式代码验收及正式整理记录分别保存，不将计划数量视为实际删除数量。

## 性能说明

浏览器负责页面交互、图形绘制和地图WebGL渲染，受客户端CPU、内存、显卡、驱动和硬件加速影响。网络负责传输页面、数据及底图瓦片；服务器负责查询、瓦片生成和计算，模型还受模型服务GPU及排队影响。页面拖动缩放卡顿与请求等待缓慢应分别诊断。本次取消持续装饰动画及首页概览请求；旧电脑的实际性能需在该电脑测量。

## 验证及发布

具体本机检查、候选和正式验收回执保存在本轮独立运行目录，绑定同一冻结提交。接口结构、权限代码、数据根路径与栅格后端渲染方式保持。
