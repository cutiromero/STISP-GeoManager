# 数据分析展示范围修正（v0.1.23）

本记录替代 v0.1.22 的数据入口范围：数据分析目前是展示模块，只保留并默认打开胡杨案例。通用化指分类分布、数值分布、指标关系、明细与字段选择逻辑可适用于不同领域，不代表自动纳入当前项目资源。

页面不请求资源列表、真实资源统计或查询接口，算法测试数据继续留在原资源目录和计算流程中。移除只为资源目录服务的分类筛选、地理/非地理过滤和处理跳转，保留按实际字段选择分类与数值指标的图表。原浏览权限仍生效；展示案例沿用内置示例说明。

无 API 契约、数据存储、后端权限或栅格渲染变更。浏览器测试检查单一胡杨案例、忽略历史筛选链接、不读取项目资源、通用图表选择和浏览权限。发布沿用候选、生产验收后推送同一提交的流程，验收账号仅保存在隔离候选数据库。
