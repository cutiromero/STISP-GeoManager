# 智能体历史恢复与响应诊断

版本0.1.55，2026-11-03。

## 页面行为

- 快速对话、科研智能体共用的历史打开流程，先读取和核验响应，再切换会话。加载期间保留当前聊天。
- 历史结构错误、网络异常时保留已确认内容，局部显示“重试加载历史”和“下载异常诊断”。首次打开失败时显示加载失败，不用空历史模拟成功。
- 空闲聊天取消每15秒整段历史刷新。运行中任务仍使用原增量轮询，并在每次响应核验后更新；短暂异常保留已有回答、显示重试入口。
- 后端逐次鉴权继续执行。明确401/403按现有权限边界清理内容；明确404移除不可访问的会话。异步过期响应不能覆盖新选会话。

## 响应核验与诊断

API使用现有生成DTO，增加赋值前运行时核验，不修改OpenAPI、接口、权限或后端数据。

- 会话列表的items必须为列表，会话详情的runs必须为列表；每条运行记录与必需的内层列表核验后使用。
- 对话和任务身份必须对应所请求的对象；返回合法空列表是有效历史，缺字段、null、HTML或不完整JSON分别作为异常。
- 普通提交、取消、问题卡回答和计算意图返回的运行记录也进行核验。
- 主动取消的请求沿用AbortError，不当作格式错误记录。

异常保存在当前浏览器标签页的sessionStorage，键为`platform:api-response-errors`，最多20条。刷新后保留，关闭该标签页后由浏览器清理；控制台也输出同样的结构化记录。这里是浏览器端诊断，后端没有新增收集接口。

每条记录包括时间、当前页面、请求地址、最终响应地址、最终地址是否可获得、HTTP状态、Content-Type、redirected、核验失败位置，以及真实字段名称、类型和数组长度。结构展开限制为4层、每层60个字段、数组前三项，总节点预算300；达到限制有明确标记。

最终地址保留协议、主机、端口、路径和查询参数名称，查询值与URL凭据脱敏；不保存聊天、工具结果内容、HTML正文、Cookie或Token。测试生成的Response没有最终URL时，以请求地址辅助定位，并记录finalUrlAvailable=false，不冒充实际最终地址。

## 坐标提示

`coordinate_uncertainty`来源是坐标小数位数对应的数值精度估计：以最后一位的半单位，按纬度换算成米，再比较最大最小比值。没有与实测参考坐标比较，不能作为真实地图偏移或定位精度判断。

极小值按6位小数显示时都可能成为0.000000米，仍具有较大比值。地图自动加载时取消这一类弹窗；缺少几何、经纬度越界等质量告警和后台导入校验继续保留。

## 验证范围

定向浏览器回归覆盖缺runs、null、对象、错误列表项、错用messages、HTTP200登录HTML、坏JSON、请求跳转、错会话、错任务、异步乱序、局部重试和明确权限拒绝。诊断验证真实字段结构、脱敏、容量限制与浏览器存储不可用时的行为。

交互测试覆盖45秒空闲不重复加载历史、运行中增量回答继续恢复、异常响应保留已有消息。地图通知测试覆盖精度提醒过滤及其他质量提示保留。

实际服务器发布状态、冻结SHA和验收结果以本轮独立发布回执为准。此次修复封住已确认的前端覆盖缺口；szf那一次异常响应的原始内容仍未取得，新增诊断用于后续核对其来源。
