# 大屏公共展示与成果选择

## 公共框架

项目大屏共用`MonitorDashboardFrame`、图层状态区、成果来源选择和地图显示更新组件。地图操作区保留定位、缩放和对比控件；加载、显示更新、错误和图例入口放在地图外的公共信息区。

桌面采用地图与信息双区布局。右侧六张业务卡片按两列三行铺满可用高度，卡片内容在各自区域内滚动；窄屏采用纵向布局。各场景沿用统一的高度、间距和状态展示规则。

## 成果身份

成果选择分为本次解译、历史解译、标准成果和其他上传成果。

- 本次解译依据当前业务流的真实批次编号匹配。各样区只显示该批次产生的成果；尚未生成时显示原图和当前任务状态。
- 没有当前任务时，最近一次本人解译作为独立入口，显示批次与处理时间。
- 历史解译保留多个批次和版本，显示处理时间、批次编号、处理人及解译模式。
- 标准成果由用户从当前项目有权访问的上传分类栅格或矢量资料中明确选定，也支持已按标准用途登记的监测产品。
- 其他上传成果按原登记身份展示。

系统解译来源由实际成功计算、标准入库记录和业务流步骤批量关联，包含任务编号、批次编号和处理时间。本人可打开原业务流记录；其他处理人的私有记录只保留成果批次信息。标准资料和显示选择继续使用数据目录的项目、资源及本人范围权限。

切换历史记录用于查看所选记录，当前任务的身份保持独立。新任务启动后建立新的当前批次；任务完成时刷新成果并定位该批次。

## 类别与显示更新

类别显示只改变后端显示规则和地图图层。当前成果在新样式准备期间保持可见，新样式的可见瓦片就绪后统一切换。快速连续操作会取消过时的显示请求；超时或显示失败保留当前画面，在公共状态区说明问题。

显示样式按资源修订与类别组合进行有界复用。资源切换、权限失效和项目或账号切换采用各自的失效边界，当前项目资料与科学成果继续由原平台权限和登记记录约束。

## 下载与资料元信息

地图和下载按账号、项目与资源修订复用同一份有界资料元信息。账号、项目或资源修订变化后重新读取；取消的迟到响应不会进入缓存。栅格下载使用该资料实际关联的数据集编号，并由导出服务重新核对数据集与资源权限。矢量资料通过地理工作台的现有导出入口处理。
