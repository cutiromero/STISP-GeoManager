# 遥感监测成果展示

监测大屏服务于项目汇报，采用地图与区域指标两栏布局。完整窗口包括项目场景、实际观测期和关键统计。地表覆盖显示地类构成，互花米草突出分布面积和斑块数量，野火突出面积或火辐射功率密度。缺失值不换算为零。

## 正式成果

先在「业务流」准备输入并运行。计算任务执行完毕后，图件和统计进入「数据中心 → 任务成果」，以业务任务或独立计算及启动时间归档。符合质量条件的监测主地图可在此确认登记。确认后仍沿用成果与来源访问权限；可见范围未扩大。既有已登记监测产品仍按原来源展示。其他计算附件不会单独上屏。

区域以登记栅格的经纬度范围识别，野火不同观测产品分别组织。同一地区与口径采用最新可见观测期；同一期只展示最新登记。没有登记观测时间时明确标注未知，不能使用任务或入库日期代替。

## 演示操作

可全屏、刷新和切换区域。自动轮播在可见前台运行；手动切换后暂停，支持偏好减少动态效果。切换仅改变所显示的已登记地图与统计，不启动业务流、计算、框选或重放历史批次。
