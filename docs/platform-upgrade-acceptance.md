## 2. 用户可直接检查的改动

### 项目和入口

1. 未登录访问根地址，首个模块是地理工作台，第二个是数据资源；不再进入首页门户。
2. 超管进入项目标签管理，新建标签并维护名称/说明/排序/启用状态。默认项目受保护。
3. 管理员选择用户，为同一用户分配多个项目；普通用户只能看到默认和获配标签，超管可见所有。
4. 切换标签会提示先保存，随后清理已加载工作台图层和请求。“全部可访问”只用于聚合浏览；编辑、地图查询加载、导入和导出请选具体项目。
5. 撤回用户标签后，该用户下一次访问对应 API 返回无权访问；角色管理权限并不自动授予所有私有内容访问权。

### 科普与新闻

1. 科普按遥感基础、GIS 与地图制图、空间智能感知、时序与时空分析、地理知识与基础模型、应用案例六个方向浏览。
2. 首批提供 12 篇知识文章、12 张选取的课件插图、24 个学习入口。正文和素材按主题组合，没有课程播放器或八讲学习导航。
3. 新闻已有 1 条会议动态，记录 2026-09-11 活动，含报告封面、7 张会议照片、2 份 PDF。主讲/议程信息依据原素材，未推断照片人物。
4. 有内容管理权限者可打开“管理内容”查看草稿，进入详情编辑正文、分类、摘要、来源、外链、活动日期、置顶与发布状态。
5. 先保存新建草稿，再上传图片/PDF；可选封面、改图注、移除附件和预览正文。保存冲突提示重新加载，保留当前编辑；上传附件不会覆盖尚未保存的文字和图注。
6. 默认项目已发布内容匿名可读；私有内容仍受项目成员限制；草稿/下架媒体不向普通读者公开。

### 在线制图

1. 在具体项目中加载数据，保存或选择一个地图工程，从原专题制图入口创建/打开出图稿。
2. 在纸面选中标题、图例、主地图、比例尺、指北针、区位图等要素，拖动调整位置，使用缩放控制点调整尺寸。属性以毫米表示。
3. Shift 多选；方向键 1 mm、Shift+方向键 10 mm；可切换 2 mm 吸附，使用锁定、隐藏、层级、对齐和等距分布。
4. “平移地图内容”调整主地图内容范围，关闭该模式后移动地图框。额外文字可以新增、编辑和复制。
5. 支持 50 步撤销/重做、4 秒空闲自动保存和手动保存。保存失败暂停自动保存并保留草稿；多人/多标签页改同一稿的旧时间戳保存返回 409。
6. 沿用 A4/A3，PNG/JPG/图像型 PDF；默认 300 DPI，可输入 72–600，仍受 8192 单边和 3600 万总像素上限约束。超限组合不能导出。

当前内置要素为单例，删除键执行隐藏；文字可以复制。任意图形/插图、多独立地图框、任意要素复制和 ArcGIS 工程格式互通不属于已实现能力。
