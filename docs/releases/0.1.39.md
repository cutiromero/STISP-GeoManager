# 0.1.39 科研工作流成果与暂停

本轮优化原生态风险和地质模拟两个案例，并复用到科研工作流公共界面。

## 用户操作

1. 在成果展示进入原生态或地质模拟案例，照常提交自然语言任务。
2. 处理中当前步骤自动展开，已完成步骤可逐项展开核对；结束后分析过程和计算历史收起。
3. 末尾“生成的文件”集中展示 Markdown 报告、CSV 表格和空间成果。前后期与检查、修正、复查按实际任务区分，过程文件可展开。
4. 报告及表格可以在线预览、下载到本机；有数据新增权限时可以手动入库，界面显示项目内的实际目录位置。地图文件沿用地理工作台查看入口。
5. 科研任务点击“暂停任务”并确认后保存进度，点击“继续任务”从暂停位置处理。暂停停止新步骤和新入库请求，已经提交的计算和入库队列独立完成。原人工复核继续保留。
6. 普通对话点击“停止回答”后确认，已经生成的回答保留，可以提交新消息。

## 流程与输出范围

两个旧 Demo 的阶段顺序是预设的：生态经过两期指数、变化提取、调查排序及总结；地质经过检查、几何修复、复查、受约束编辑及总结。模型依据真实资料、知识和计算结果在阶段允许操作内作判断，需要人工复核时停下等待。说明与对应任务、输入和产物持久关联。

本轮报告为实际 Markdown 文件，表格沿用实际 CSV 输出。报告汇总多个计算步骤，保存到配置指定的研究目录，登记后归入本项目“计算结果”，默认仅本人可见。每次读取、下载与入库重新检查关联资料和知识权限；文件校验不一致时拒绝读取。

## 验证与发布

本机使用已有完成的生态及地质模拟工作流检查真实报告：生成、重复生成、预览、完整下载、入库及重复入库；既有计算任务数量与计算入库记录数量保持一致。并发生成/入库、撤权及暂停恢复通过相关后端测试；前端验证折叠、文件动作与确认操作。

API 契约、开发说明及生成类型同步更新。新增 agent.0016_workflow_pause 迁移，包含暂停字段及活动任务约束；发布先备份数据库，再迁移与切换平台服务，模型及知识服务保持原配置。生产构建使用 `/static/` 路径，并验收实际静态文件内容类型及哈希。最终部署身份与验收记录保存在同提交的独立服务器回执中。
