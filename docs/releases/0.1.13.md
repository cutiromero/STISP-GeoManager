# v0.1.13：智能体生成控制与两个计算算法

## 参数来源与生效范围

旧模型总窗口32768来自服务器manage_models.sh中的启动参数，不是Qwen3.8-27B的固有上限。旧生成上限4096来自平台保存策略，经worker作为max_tokens传给模型，包含思考与正文。

本版提供reasoningEffort（low/medium/xhigh）、maxContextTokens与最高32768的maxOutputTokens。每次生成前调用实际服务的分词接口，验证输入＋生成预留＋256 token安全余量不超过模型窗口。管理员保存的新生成参数用于新开始的任务；权限与取消实时核验。

| 参数 | 执行位置与效果 |
| --- | --- |
| 生成上限、Temperature、Top P、思考强度 | 模型HTTP请求；端到端测试捕获两组保存值与请求一致 |
| 输入token预算、文本字节保护 | 完整请求发出前检查，必要时裁剪历史或附件，保留当前问题 |
| 模型总窗口 | 模型服务启动配置；网页读取实际服务值，修改输入预算不会扩大模型窗口 |
| 工具步骤、协议重试、资源数 | 智能体工具循环及数据读取边界 |
| 每日次数、并发、允许用户、功能开关 | 平台接入、排队和执行权限检查 |
| 单次最长秒数 | worker运行期限及上游连接取消 |
| 附件数量、大小、文档开关 | 上传与任务附件读取 |
| 工作流算子步骤 | 工作流提交算子的限制；当前工作流执行单次计划 |
| 最大迭代轮次 | 兼容保留字段，当前没有自主迭代实现，界面标为预留并禁用 |

部署目标为真实模型窗口65536、生成上限16384、输入预算49152、默认中等思考强度。候选模型已报告65536并接受16384请求；最终生效值以服务器验收回执为准。本地开发模拟模型单独报告自己的窗口。

## 算法及排序

- NDWI水体指数：绿光与近红外反射率，应用scale/offset，保留坐标、NoData和零分母掩膜。
- 矢量面积与周长：WGS84椭球面积与含孔洞边界长度，保留原属性和坐标系，字段冲突或无效面明确报错。
- 模板顺序按栅格、矢量、表格组织；算法列表在分页前按分类排序值、分类名、算法名、ID排序。
- 算法通过标准登记、真实运行、数值核对、发布接口上线；人工验收输入放在独立私有验收项目，保留结果供追溯。
