# 业务流中的遥感资料与观测时间

遥感任务在当前项目的业务流页启动。地表覆盖选择一幅原始 RGB GeoTIFF；互花米草选择三幅同年、同网格的已登记季节影像；野火选择已登记的原生 SeasFire 立方体、实际变量和观测期。各任务按绑定资料的有效全域处理。

资料导入时在当前项目核对坐标、单位、波段、实际观测期及使用范围。原生立方体登记保留时间坐标、产品有效掩膜和原始时空索引。异常数据须纠正或重新登记，不能用业务任务的启动日期填补观测期。

野火变量按真实观测时相读取。GWIS、GFED、FCCI 为火烧面积，CAMS 为有效格网火辐射功率密度。观测任务可以附带多期汇总，实际边界和序列长度以资料可用窗口及算子预算为准。未知与缺测保留为空，不能理解为无火或零风险。

任务完成后，在数据中心查看并登记正式地图；展示端仅以登记产品及观测元数据为依据。
