# 时空监测工作区

## 操作路线

1. 在“数据目录”的资料详情中维护“监测用途与时相”：按场景选择原始输入、解译成果、标准参考或辅助资料，填写资料集合及实际观测时段。
2. 在大屏点击“选择资料与时相”，在侧栏选择资料集合和时相，完成后返回地图。互花米草按方法要求选三时相组合；野火选择原始容器、监测内容、年份和实际观测时期。
3. 在地图底部将时间对象切换为“原图”，用日期框或前后箭头查看已有影像；日期框可搜索年份和日期。需要限定区域时点击框选，在地图上依次点击矩形两个对角；也可使用当前视野或输入经纬度。未设置范围时使用所选数据的共同覆盖全域。
4. 开始任务，核对资料、日期和范围。互花米草选择监测年度的三期组合；野火选择监测内容和日期，趋势统计默认“仅当前期”，也可选择近1个月、近3个月或近1年。展开“输入、输出与参数说明”可查看用途和选择依据。
5. 在时间条选择“原图”或“成果”，日期切换应用于对应图层。“循环播放”连续播放并在末期回到首期，原图和成果图层准备期间等待加载，显示失败时停止循环，可原地重新加载。同一时期的不同计算批次从成果列表选择。仅一个时期时显示观测期；互花米草成果显示三期共同形成的“联合解译”时段。原始图层和成果可独立开关，透明度在资料侧栏调整。

大屏成果分为最近解译、历史解译和登记成果。上传成果及标准资料统一从登记成果选择，资料原有用途和来源记录保留。

## 资料与时间

资料用途独立于原件和计算产物的来源标记。人工上传的历史解译图属于成果资料，不能因为它不是平台计算产物就自动归为模型输入。用途维护不改变原始文件、备份或来源。

月精度存储月初至月末，年精度存储年初至年末；日精度使用同一日期，时段精度保存真实起止日期。原生时空容器的时间点和产品有效性从时间坐标及有效掩膜建立索引。目录与年份查询只访问数据库，不扫描时空像元。

资料集合用于区分不同监测系列。栅格组合还需满足已发布方法的波段数、类型、坐标网格与时间顺序；同一期多个登记版本优先采用最新登记，原件保留。每页最多200项资料，可以切换集合或翻页；原生时期按实际坐标分页，每页最多500项；省略年份可连续查询全部时期，不以966期为上限。

现有RF保留3月、8月、12月三个输入位置及48特征顺序。月份和同年规则由已发布方法声明，目录自动匹配各年度组合。新年度的三期登记齐全即可选择；其他月份可按时间浏览原图，其他季节组合须登记对应模型。输入日期固定到计算快照，后台同时核验月份和年份。

## 地图与计算

普通栅格通过既有后台符号化及XYZ瓦片显示。巨幅无概览输入先构建独立显示包装及降采样概览，原生网格和像元保持一致。显示包装不替代计算输入，计算仍按原件的研究区窗口读取。RF的显式流式端口按256×256块执行，全域不分配整幅48特征数组；8连通斑块跨块合并。非流式算子仍使用原有整幅像元限制。原件路径、物理身份和窗口共同绑定执行输入版本。全域输出须与冻结原始输入的网格、大小和坐标系一致，波段数受输入端口上限约束，物理文件大小与逐块内容校验继续执行。普通算子仍使用1亿波段像元的输出限制。巨幅成果使用保留完整原生细节的虚拟投影显示视图及最近邻按需瓦片，沿用逐次权限检查、并发合并和有界缓存；普通分类成果仍使用完整静态瓦片。全球观测的Web Mercator显示裁到有效纬度，科研输出和统计保留完整原生全域。成果下载保留原始网格、掩膜和地理参考；不重投影、不裁剪的独立GeoTIFF直接按原生文件交付。

地图样式就绪即装载业务图层，外部底图瓦片继续异步加载；初始化期间状态栏显示加载提示。地图显示先核对当前源文件身份、规则和瓦片清单。连续栅格、按需瓦片及已完整生成的分类瓦片直接返回可显示结果，不进入重任务队列。同一账号、项目、资料版本与规则的并发准备请求复用一个任务；失败后可重试，文件或规则变化后重新准备。普通分类瓦片首次生成仍受原重任务并发限制。切换栅格成果时保留上一幅图，直到新图瓦片与画面就绪；权限失败立即清除旧图。

野火原始图层通过独立的有界单工作线程生成单期预览，最多等待4项，单期空间网格不超过110万个像元，保留有效掩膜和物理单位。预览使用对数显示拉伸、正值着色、零值及缺测透明，显示变换不进入观测统计。FCCI使用月内重复记录的均值。显示缓存限制为64幅，重复的同源同日期请求复用准备任务。

预览、任务读取及图像下载均重新校验当前项目、成员、资料用途、访问权限与资料修订。任务取消或切换来源后，页面中止等待；已销毁地图不再添加或删除图层。原始预览属于派生缓存，不登记为新的原始输入。

业务流沿用同一主执行记录、算子预检、输入版本、计算队列和标准入库。计算产物登记为成果用途，并关联观测时段。已有成果清单保持不可覆盖；展示时可依据已登记原始时相补充时间，不使用创建时间替代观测时间。

## 维护接口

- `GET/PATCH /api/catalog/resources/{resourceId}/observation-metadata/`：用途、集合、时间及来源结构。
- `GET /api/catalog/observation-metadata/?ids=...`：批量元信息，每次最多100项。
- `GET /api/ecology/monitoring/sources/?scene=...`：可用原始资料、当前方法和时相组合。
- `GET /api/ecology/monitoring/source-times/?scene=wildfire&resourceId=...&year=...`：真实观测时期。
- `POST /api/ecology/monitoring/source-preview/`：准备原生单期图层；后续使用返回的任务编号查询状态和读取图像。

全部接口显式传入当前项目。资料维护由资料维护者的编辑权限或管理员权限控制；普通查看者可以浏览其获授权资料。

批量维护可使用 `manage.py set_monitoring_metadata --project <项目编码> --actor <维护账号> --resource <资料编号> --metadata-json '<元信息JSON>'`。原生容器登记时自动建立实际时间索引。算子通过 `register_spartina` 或 `register_wildfire` 的 operator、trial、publish 三阶段登记，试运行显式提供原始资料；四界全部省略时从授权原始网格推导共同覆盖全域，部分省略时提示补齐。

## 数据名称与用途

资源名采用“内容＋观测时间”，同时间多批次使用简短序号；来源、单位、分辨率、模型版本和任务身份保存在详情中。显示名变更不改资源编号、原始文件名或不可覆盖成果清单。

| 名称示例 | 用途 |
| --- | --- |
| 互花米草影像·2025-03 | 三季节模型的3月输入，也可单独查看原图 |
| 沿海真彩色底图 | 定位和选择研究区 |
| 互花米草历史分布 | 浏览已登记分布面 |
| 互花米草分布（2025-03至2025-12） | 三期联合解译的空间分布 |
| 互花米草分布概率（2025-03至2025-12） | 查看模型对目标类别的概率 |
| 全球野火观测数据（2001–2021） | 按产品和日期提取原生观测 |
| 野火变量说明／野火观测日期／野火气候指标 | 查变量单位、可用时期和环境指标 |

## 趋势统计的选择依据

野火观测日期决定当前地图显示哪一期；趋势统计决定区域序列向前覆盖多久。仅当前期适合本期制图，近1个月适合近期变化，近3个月覆盖约一个季节，近1年用于年内季节比较。平台按日历时间寻找实际可用观测期，展示对齐后的起止日期，再换算执行期数。FCCI按月统计；其他产品按原始周期，缺测保留为空。趋势范围不改变当前期的原值图，也不是模型预测步长。

## 成果解读与任务状态

成果说明优先呈现当前成果的真实面积、占比、主要类别、观测时间和统计范围；缺失指标不填零。互花米草概率不解释为准确率，单期成果不推断增减趋势；野火历史格网观测不解释为实时预警或精确火点；胡杨演示研判引用当前模拟读数并保持演示标识。任务交付遵循先结论、后依据与成果入口的顺序，复用有效预检和入库证据，输入变化后重新核对。

待审核任务明确提示打开任务处理。审核后直接完成的任务也只刷新一次成果；后台活动任务在页面隐藏后停止轮询。地图或原图加载失败可点击“重新加载”，处理记录为空时显示操作提示。
