# 页面登录恢复与多标签交接

平台使用Django Session及页面令牌控制登录生命周期，令牌仅存放于标签页sessionStorage。主动退出、账号停用、权限撤销和关闭全部页面后的新访问仍受现有认证约束。

## 误退出原因

短访问租约与浏览器页面存活并不等价。后台标签页节流、主线程长时间繁忙、休眠和断网都可能推迟30秒心跳。若超过120秒后连持有正确令牌的原页面也拒绝续期，后续数据请求就会被误当作已退出。

新对比页通过noopener打开，需要独立登记页面。将短时间内收不到BroadcastChannel响应直接处理成整浏览器注销，会使原页面及仍在使用的其他标签同时失去登录。

## 页面行为

已登记且未挂起的页面可凭原令牌在访问租约结束后12小时内恢复。页面回到前台或请求数据前按需续期，并发续期合并；临时网络失败和8秒续期超时保留登录状态。JSON数据请求仅在401且合法续期成功后重试一次，复用原请求内容与幂等键。

新标签优先同源交接，交接不可用时可join当前仍有有效页面的登录会话。join需要已认证Cookie和CSRF。没有在线页面时不能凭旧存储或Cookie自行恢复。abandon不注销其他标签，不删除共享Cookie。

pagehide立即挂起当前页，正常刷新允许120秒凭原令牌resume。旧请求序号不能覆盖新状态，挂起页不能用heartbeat恢复。页面恢复与再次登录均隔离旧异步请求。familyId只关联同次登录的退出通知，不作为访问凭据。

## 验证与发布

回归范围包括后台超时后恢复、无令牌Cookie重放、错误令牌、恢复期限、无在线页join、CSRF、显式退出、迟到响应、新旧登录与BFCache竞态，以及JSON请求重试。服务器候选与正式浏览器验证使用独立验收会话，模拟页面租约失效和无BroadcastChannel新标签，不启动科学计算或修改科研数据。

现有登录页面和操作入口保留。正常使用及等待逻辑推理结果时保持登录；真正失去认证时仍进入登录页。API契约、生成类型及开发说明随页面会话协议更新。项目权限、资料权限、数据根、算子2.2和栅格渲染方式保持。
