# 新版科研智能体

在智能体工作台选择「新版」进入 Hermes 科研会话。快速对话也提供新版入口。会话按账号和项目归档。Hermes 负责模型调用、上下文、工具、技能、任务清单和会话事件。Django 负责登录、项目授权和数据服务。

## 会话进展与来源

一轮会话的阶段消息、工具和算子记录按发生顺序显示在进展区。回答完成后可从用时入口展开记录。点开工具行可查看每次调用的状态，点开「思考过程」可查看模型返回的思考内容。

正文中的证据编号可打开本轮会话里的来源，查看文献标题、定位、摘录和可访问的原文链接。工具生成的计算任务可以从会话打开计算中心。

千问 Qwen3.8-27B 提供关闭、轻量、标准和深度四个思考选项。新版会话的输入栏显示联网检索入口，由平台策略与会话开关共同控制。

## 开始科研任务

1. 在新版输入区点击「业务流」，选择发布版本，填写任务目标，点击「开始业务流」。
2. 在新会话中通过「选择系统数据」添加资料。可在登记数据与计算成果之间切换，按名称、说明和目录筛选。
3. 发送任务后，Hermes 读取业务流的科研路径，并建立任务清单。它可以根据资料和运行结果调整计划。用户可在会话中补充资料或回答澄清问题。
4. 点击「查看计算任务」，在计算中心跟进状态、预览或下载成果。计算登记后的资料可以从系统数据选择器中加入后续任务。

## 发布版本与工具

`get_research_workflow` 根据项目与发布版本读取建议步骤、依赖、资料用途、候选算子和交付目标。Hermes 使用上游 `todo_list` 管理任务。会话展示 Hermes 返回的清单和进度。

`deploy/hermes/plugin` 使用上游插件接口注册平台工具。数据与知识工具沿用平台服务，计算工具通过计算中心提交任务、读取结果和登记成果。计算任务记录当前项目、提交账号和会话关联。项目数据、工具和结果读取由平台授权。

科研技能位于 `deploy/hermes/skills`。技能按 Hermes 的 `SKILL.md` 格式登记，包括适用任务和需要的工具。当前提供科研业务流、地质综合推理、遥感监测、来源核对、arXiv 检索及文档行动项整理。管理员启用公开检索后，用户可按会话开启联网工具。

## 自然语言启动与算子副本

在新版输入栏发送「在当前项目做逻辑推理，先核对岩性图、断层线和研究区，再给出需要复核的图斑」。Hermes 可按流程名读取发布版本，在项目中查找资料，并在需要时询问用户选择。选择系统数据的入口也可用于指定资料。

`inspect_research_operator` 提供当前发布版本的输入、参数和交付文件。具有算子源码读取权限的用户可让 Hermes 按 Python 文件和行偏移查看源码。计算失败时，运行结果提供结构化诊断与可用的源码位置。资料类型和字段差异可先通过清单参数或数据衔接处理。

在需要调整 Python 逻辑时，`submit_research_compute` 接收对应源码片段的替换内容。计算中心从发布包生成该任务的执行副本并检查副本摘要，使用独立运行目录执行。任务记录关联的发布包摘要、此次修改的文件摘要和重试来源。后续重试可按任务编号查看和继续修改该副本，新提交可从发布版生成另一份副本。适配适用于目标运行环境支持隔离的 Python 地理计算算子。

逻辑推理由四个可独立调用的算子组成。检查算子生成问题清单，也可复核修改后的图件。用户在会话中确认的地质处置生成同一会话的工作表。处置算子用已登记的检查清单与处置表生成派生图层。构造关系与远景算子可以按用户目标、现有资料和前序成果组合执行。

将一次性脚本登记为算子时，按可独立验证的输入与产物切分。每段公开所需参数与输出，前一步成果可作为后一步资料，便于 Hermes 单独选择和重跑。

## 本机运行

1. 用 `stisp-geomanager` 环境配置独立业务和科研目录，并在开发 TOML 开启 `runtime.debug`。运行 `python manage.py migrate`，再启动 Django 和前端开发服务器。
2. 在仓库根目录运行 `/opt/homebrew/Caskroom/miniconda/base/envs/stisp-geomanager/bin/python scripts/run_hermes_web.py`。脚本使用固定版本的 Hermes，启动回环网关。按提示输入 DeepSeek API 密钥，或在启动进程时设置 `DEEPSEEK_API_KEY`。
3. 登录具有当前项目权限的账号，打开新版智能体。需要验证算子时，启动计算中心和相应的算子运行环境。

## 服务器运行

按 `config/mh-agent.example.toml` 将网关设置保存在业务数据目录的 `config/mh-agent.toml`。填入 Hermes 可执行文件、千问模型端口、模型 ID 和模型上下文长度。平台启动入口托管独立 MH-agent 网关。候选运行使用独立数据根和回环端口，通过标准 `full` 发布入口验证模型工具调用、会话授权、SSE 和幂等。

浏览器通过 `/api/agent/hermes` 访问 Hermes Sessions、Runs、Capabilities、Skills 和 Toolsets。创建运行携带 `Idempotency-Key`，事件流按 Hermes 的事件序号续接。浏览器使用平台的会话 Cookie、CSRF 和 `X-Project-Id`。

Hermes 固定版本为 `0f602c5f6f18615632535251d62a2db74ce93b69`，许可证见 `deploy/hermes/NOTICE-HERMES.txt`。
