# 海德乌拉独立评价与制图整理准备

## 两种验证分别看什么

正式演示验证知识引用、测量、批准、实际修改、复核、地图及报告是否对应。
独立评价则在带私有标签的模拟副本上统计候选检出情况，观察置信度证据及构造复检的影响。
两者共用正常检查算法源码，评价标签和参照地图只进入独立评分脚本。

原交付包把 L-03 名称代号校验归入“地层接触”。本次将其单列为属性一致性：

| 关系或检查项 | 当前可评价的具体范围 |
| --- | --- |
| 地层接触相关候选 | L-01 地层局部包围、L-02 早期岩体局部包围；保留残留体等地质例外 |
| 属性一致性 | L-03 名称代号；这不是地层接触关系完整验证 |
| 岩性共生相关候选 | L-04 本模拟的火山岩与高变质背景组合 |
| 构造切割相关候选 | S-01 覆盖层内线性体、S-02 沿界线形、S-03 孤立短线、S-04 急折返 |

这些检查项没有覆盖真实地层接触解释、全部岩性组合或构造切割时序。
查全率和查准率用于本模拟候选检测；检出、获批和实际修复分别统计。
遥感矿物识别没有独立地质标注，本次只给规则命中与处置统计。

## 相同单元整理案例

`scripts/geology_multi_evaluation_prepare.py` 只读当前运行资料、冻结名称代号表及构造，
选择几何有效、名称代号一致、模拟置信度较高、面积适中且能够安全分割的图斑。
在副本中将它分成属性相同、真实共享锯齿线的两个图斑。
这份资料明确标为“演示整理副本”，展示经批准去除冗余内部边界。

准备过程不读取地质参照图选择对象，不编造野外调查，不改变岩性类别。
正常运行输入只保留既有字段和中性对象编号，没有恢复父面的标记。
父面、反向映射与准备清单仅保存在独立私有目录，供验收覆盖范围、面积及正常区域是否保持。
正常算法依据同名称与规范代号、共享边界及构造保护条件检测候选，再按用户批准融合。

准备命令在已批准的项目环境执行：

```powershell
. ./activate-local.ps1
& $python scripts/geology_multi_evaluation_prepare.py `
  --inputs '<现有资料根>/inputs' `
  --output '.runtime/geology-complete-story-20261025/evaluation/cartographic-case'
```

每次输出目录要求为空，已有资料与证据不覆盖。

## 独立标定与对照

`scripts/geology_multi_evaluation.py` 按以下顺序运行：

1. 核对原包校验值，将当前四算子及核心模块复制到本次独立源码快照。
2. 安全提取原包已阅读的纯模拟函数与常量，不导入整脚本，不执行其顶层建目录或 `main()`。
3. 用标定种子生成副本；将注入标签、参照图与映射保存在 `private/`。
   正常 `runtime/` 仅含中性编号和运行字段。
4. 真正调用 `geology-multi-check` 的 `run(context)` 测量标定集。
   阈值扫描只使用标定集标签，先冻结所选阈值及选择目标是否满足。
5. 冻结后才生成另一随机种子的测试集，分别运行第一轮、构造建议排除后的复检、
   禁用模拟置信度筛选的“仅规则”对照。
6. 算子返回后，由独立评分代码读取私有标签，重新计算分规则、分具体项目、分关系的 TP/FP/FN。
   构造全部模拟异常与有对应规则子集分别报告。
7. 再核对原包全部校验值，保存每次正常算子的输入、输出及源码哈希。

“构造建议排除后的复检”是明确的独立对照：在评价副本中保留线的几何，
假设采用所有构造复核建议，以测量其对岩性复检的影响。
该控制实验不是正式用户批准，也不会写入平台资源或启动工作流。

标定与测试共享同一示范区底图，随机错误的位置、类别和置信度分别生成。
它们是独立随机副本，不是独立研究区或实际识别模型的外部验证。

```powershell
. ./activate-local.ps1
& $python scripts/geology_multi_evaluation.py `
  --source '<海德乌拉交付包根目录>' `
  --prepared-inputs '<现有资料根>/inputs' `
  --output '.runtime/geology-complete-story-20261025/evaluation/run-v102'
```

`evaluation-summary.json` 中的 `sections` 提供可发布的简短评价章节。
可发布文件为 `metrics-by-rule.csv`、`metrics-by-relation.csv`、
`confidence-calibration.csv`、`structure-all-vs-covered.csv` 及 `evaluation-report.md`。
正常服务只提供经过权限控制的评价摘要与这些文件，私有标签、原始映射和参照不作为普通资源发布。

## 实际空间关系的独立对照

评价另将运行图和独立地质参照按规范代号分别合并，再实际量算不同单元间的共享线。
点接触不计为线接触；分别统计接触单元对及其线位置在0.5米容差内的覆盖程度，
并区分地层—地层、侵入岩—地层、侵入岩—侵入岩。
这些结果评价地图中的接触位置和单元标签，接触性质、侵入期次及真实地质解释另需专业证据。

`structure-measured-items.csv` 将正常检查返回的每条线的覆盖比例、沿界比例、弯曲度、
孤立性和折返数，与独立模拟异常类型对应。
小型独立几何控制另验证：点接触不算线接触、沿界线不等于穿过两侧内部、
高置信度岩性组合候选保持例外复核状态。

源码稳定后可用 `--fixtures-from '<上次完整评价目录>'` 复用已有独立随机副本，
重新快照源码、重新只在标定集选择阈值，再读取测试副本重跑。
每轮结果存新目录，原回执保留；源码和算子版本均以各轮哈希记录。

真实融合完成后的独立核验由 `scripts/geology_multi_evaluation_verify.py` 完成：
读取实际前后图层和算法changes表，在算法结束后才读取私有准备记录与参照。
核对获批两面恢复、正常对象保持、类面积与外边界保持、移除的内部边界长度，
将涉及对象面积、几何覆盖变化面积和分类变化面积分别列出。

这部分按真实几何及规范代号重新测量，含独立参照中的全部接触单元对；它评价接触位置与标签，
不是专业接触性质正确率。5项独立几何控制通过。
