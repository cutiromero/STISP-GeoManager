# 智能体计算活动状态修复（2026-10-12）

公开项目的 NDWI 已完成计算和入库，左侧会话仍显示等待。原因是界面将持久保存的 `computeIntent.status=submitted` 当作实时计算状态；该字段表示计划已经提交，计算结束后仍保持 submitted。

左侧会话图标与“当前任务”复用 `RunComputeTasks` 的既有查询，按本轮绑定任务的真实计算、入库和跟踪状态更新。计算中显示活动提示；自主选择是否入库时显示计算完成；已授权自动入库继续跟踪，输出全部 ready 后显示计算与入库完成。失败、停止、鉴权失败按对应状态提示。刷新重新读取实际状态，会话切换隔离旧请求；回调变化不会额外启动轮询。

完成的历史科研任务不再优先覆盖后续普通轮次；仍在推进或等待确认的科研任务保持原有优先级。

验证：3 个相关浏览器测试文件共 61 项通过，覆盖实时完成、自动入库、刷新恢复、会话切换、真实任务绑定、撤权和短暂连接失败。全前端构建及契约检查另记录于本次发布回执。此次无需 API、计算算法或业务数据变更，使用既有会话验证，不重新计算影像。

用户可见变化：智能体左侧会话名称旁的状态图标与“当前任务”随计算卡同步；计算及入库完成后显示勾选，停止流光。页面布局和原计算结果保持原状。
