# 时空智能服务平台升级计划与实现基线 v2.1

更新：2026-09-18。按用户最终说明修订；科普以知识方向组织，课件只作为图文与案例素材。本文件替代 v2 中所有八讲导航、310 页上线、课程播放器、固定人力与 12–14 周工期安排。

## 1. 已确定的需求与实现选择

| 事项 | 实现基线 |
| --- | --- |
| 一人多项目 | 用户可获配多个项目标签，管理员负责分配与撤回，普通科研用户不能自行赋权 |
| 超级管理员 | 创建、维护、排序、停用普通项目标签，具有全部项目访问权限；操作仍记录审计 |
| 默认项目 | 唯一内置 ID=1；所有人可读开放的数据和已发布图文，包括匿名访客；写入仍需相应权限 |
| 隔离 | 同库同表逻辑隔离，业务对象单项目归属；标签是权限边界，地图工程是业务对象 |
| 数据库 | 当前沿用 SQLite 元数据与 GeoPackage，新增项目外键和约束；PostgreSQL 另行评估 |
| 数据现状 | 升级前实际检查：2 个账号，项目业务资源为空；保留账号、配置和原有字典 |
| 首页与导航 | 根地址及登录默认进入地理工作台；第一模块地理工作台，第二模块数据资源 |
| 科普 | 6 个知识方向，首批 12 篇图文、24 个学习入口；从课件选择插图和原文资料 |
| 新闻 | 独立团队动态列表、详情、图集和 PDF；首条使用会议真实素材 |
| 在线制图 | 参考 ArcGIS 常用布局交互，不兼容其工程格式；扩展现有编辑器和导出管线 |
| 输出 | A4/A3；PNG/JPG/图像型 PDF；默认 300 DPI，输入 72–600，单边 8192、总像素 3600 万限制 |

## 2. 科普内容策划

| 方向 | 首批主题 |
| --- | --- |
| 遥感基础 | 遥感观测与分辨率、多源遥感数据 |
| GIS 与地图制图 | 矢量/栅格表达，投影、比例尺与地图表达 |
| 空间智能感知 | 分类与分割、训练样本与质量评价 |
| 时序与时空分析 | 时间序列与地表变化、空间与时间协同 |
| 地理知识与基础模型 | 知识约束、预训练与跨域迁移 |
| 应用案例 | 农业监测、生态环境与地表过程 |

文章使用独立标题、摘要、小节、插图、来源说明和继续学习链接。首页不按讲次、课时或页码组织，文章中的课件页码只用于素材追溯。8 个 PPTX 共 310 页是素材库规模，并非上线页面数量。课件所署 2027 年春季版本不改写为 2026 年已完成授课。

首批插图从具体页面的媒体关系中提取，再缩放压缩用于网页。保留源 PPTX/PDF，不创建全量课程播放器。正文按知识主题重新整理；管理者可继续编辑，重复初始化不会覆盖已存在的文章。学习链接为精选原始资料入口，未承诺外站永久可用。

## 3. 页面与交互

- `/`、普通登录后、Logo 返回：`/map`。
- `/data`、`/resources`：重定向 `/resources/catalog`，展示资源筛选和目录。
- `/knowledge`、`/knowledge/:articleId`：六方向知识内容。
- `/news`、`/news/:articleId`：新闻分类、列表、详情、图集与附件。
- `/projects/manage`：项目标签和成员分配管理，管理按钮由服务端能力决定。
- 原有地图工程管理保留其语义，不把地图工程的 `projectId` 当业务标签。

顶部选择器显示“默认 + 获配标签”；超管显示全部标签。“全部可访问”只用于聚合浏览，写入、加载需 POST 的地图数据、工程编辑和导出应切回具体项目。切换项目取消旧请求、重新挂载工作台并清理图层；切换前提醒用户保存，尚未保存的所有工作台状态并不会自动持久化。

## 4. 权限与数据模型

新增 `projects.Project`、`ProjectMembership`。内置默认项目不可改名、停用或删除。普通标签支持维护和停用，不提供直接删除有业务数据的标签功能。

目录、资源、图层、地图工程、出图稿、版本、成果、栅格任务、生态/组学/标准化业务记录、审计记录增加 `project_tag`。原本单字段唯一键改为项目内唯一；工程名称、活动小时统计增加项目约束。字典、物种与字段定义保留平台共享。数据库关系、批量创建、关联更新与 M2M 写入检查同项目；工程快照检查资源引用。

请求使用 `X-Project-Id` 或文件 URL 的 `projectTagId`。两者冲突返回 400；未指定默认为 1；无成员资格的私有项目返回 404；`all` 禁止写入。超管跳过成员资格限制但仍在所选项目内操作。管理员的可分配标签列表与可读取项目列表分开。

默认公开不等于任何对象均公开：资源需启用；图文需已发布；地图成果只暴露已发布版本；未共享工程、草稿、下架内容和媒体不向匿名开放。下载原文件、编辑、导入、管理仍走既有功能权限。普通项目成员也需相应功能权限使用业务能力。

后台任务继承项目上下文，开始、推进和结束时重查账户与标签资格。私有响应不允许持久缓存。匿名栅格只允许默认符号化；异步任务状态仅限该浏览器会话自己发起的默认项目 render 任务。

## 5. 文件与运行数据

所有根目录继续由 TOML 管理。默认项目研究文件保持原目录以兼容现有配置；新私有项目使用 `research/projects/<id>/...`；内容附件使用 `appdata/projects/<id>/content/<articleId>/...`。

原有成果和部分缓存继续使用全局唯一对象 ID 目录，通过受控 API 验权，不宣称已把所有文件搬入项目目录。当前不允许跨项目关联文件或工程快照；需要使用公共资料时切换到默认项目。后续如需在私有工程内直接引用默认素材，须增加显式只读共享关系与发布依赖检查。

## 6. 内容管理与首条新闻

科普和新闻共用 `Article/Asset` 模型，分类、活动日期、发布日期、来源、外链、置顶和附件均可维护。编辑权限复用 `core.manage_auth` 和超管权限。保存带 revision，陈旧编辑返回 409。支持正文预览、草稿/发布/下架、封面选择、图片说明、附件移除；附件受文章和项目权限控制。

新闻依据 China Partners Academic Forum 2026, Seminar 3 的 2026-09-11 海报与报告。主题为 Ecosystem and Environmental Research in the AI Era。议程列名与报告封面主讲人区分，报告主讲署名 Maolin Li。不从照片推断人物身份，不添加材料未证明的合作或成果评价。实际使用 1 张报告封面、7 张照片和 2 份 PDF。

## 7. 在线布局制图

沿用布局 schema version=1，新增可选编辑状态和额外文字数组，旧稿通过 normalize 补齐；采用向后兼容扩展，不强制改为 v2。

已实现：毫米坐标、纸张缩放、点选/Shift 多选、拖动与缩放、键盘 1 mm/Shift 10 mm 微调、2 mm 吸附、对齐/水平与垂直等距分布、层级、锁定/隐藏、新增与复制文字、地图框内容平移、50 步撤销重做、4 秒空闲自动保存、手动保存、关闭草稿提示、409 冲突保护、恢复标准布局。

现有标题、图例、比例尺、指北针、区位图、格网、来源和说明继续随布局导出。移动普通要素复用地图图像；单编辑器至多缓存 4 张底图，拖动结束后提交布局。栅格符号化仍由服务端生成图像或瓦片。

增强边界：内置制图要素是单例，当前“删除”行为为隐藏并可重新启用；文字可复制。任意图形/插图、多独立地图框、任意要素复制、复杂制图综合、实时多人协作、矢量 PDF 与 ArcGIS 格式互通未纳入当前实现。它们不在完成清单中冒充已实现功能。
