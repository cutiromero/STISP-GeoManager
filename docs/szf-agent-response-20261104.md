# 智能体静置异常与诊断

版本0.1.56，2026-11-04。

## 现场证据

11月3日13:48的记录对应0.1.54前端，实际错误栈落在历史消息列表的find调用，早于0.1.55上线。Chrome155、采样的主线程和堆内存记录没有显示浏览器过旧、持续阻塞或内存耗尽。

0.1.55正式代码上，在独立验收浏览器中注入缺少算法versions和项目items的响应，可分别复现reading id与reading find。该测试验证了程序缺口；11月4日老师静置时的实际响应尚未取得。

原浏览器诊断脚本保留fetch返回值和业务正文，隔离测试未发现漏return或消耗业务正文的问题。

## 页面行为

- 项目列表刷新异常时保留当前项目和已挂载页面，显示局部提示，可重试更新项目和导出诊断。
- 算法、计算任务和工作流返回值在进入状态前检查消费者所需的列表、对象和字段。缺失、null和错误结构不会被伪装成成功的空列表。
- 已显示的计算卡和研究任务可能独立查询状态，聊天完成不意味着所有计算与入库已结束。有效的后台跟踪继续执行，异常响应进入既有局部错误处理。
- 工作流审批step.action.decision继续保存approve/reject；step.decision仅提供模型判断对象或null，与既有接口契约一致。

## 一键诊断

异常页增加“导出诊断”，无需打开开发者工具。项目刷新异常提示同样提供按钮。

诊断包含编译时前端版本、实际加载脚本路径、错误栈和组件栈、浏览器标识、最近异常响应的内容类型、最终地址、跳转标志和字段结构。错误记录最多5条，接口异常最多20条，均保存在当前标签页sessionStorage。关闭标签页后由浏览器清理。

脚本地址只保留路径，错误栈中的URL去除凭据和查询值。诊断不主动读取聊天正文、Cookie、密码或文件内容。未新增自动上传接口。

## 验证与发布

定向测试覆盖项目焦点刷新失败时页面保持、错误结构拒绝、工作流审批序列化，以及诊断导出和存储受限行为。浏览器验收将正常读取既有数据与故障注入分开记录，覆盖算法目录、项目刷新和后台计算轮询。

本机验证：151项相关浏览器测试、537项前端单元测试、9项后端审核回归通过；类型检查、构建和本轮19个前端源码/测试文件的lint与格式检查通过。全仓格式命令另外报告170个未修改文件的格式问题，本轮未批量格式化这些文件。

候选、正式验收和冻结提交记录保存在本机私有发布目录。数据、权限、存储根和栅格渲染规则沿用现有配置，无数据库迁移。
