# 真实地质材料与时代属性纠偏演示

师弟提供的分类图、人工精修图、构造及蚀变成果用于地质逻辑推理项目。本轮先完成地层名称与时代属性的一致性案例，复用智能体、计算中心和地理工作台。

## 材料和当前统计

完整预测 TIF 有 41 个 class 编号、39 个名称，29 米网格，EPSG:32646。class 是稳定类别键，同名不同编号保持分开。原始 SHP 的记录与组件不一致，因此从完整栅格四连通重建 12,759 个面，回转栅格与原图逐像元一致。片段数受连通方式影响，不与原 SHP 记录数直接比较。原材料保持原样。

人工精修是师弟在原预测基础上手动修改的 484 个面。平台分别保存原始预测和人工精修，包内四张现有岩性/综合图及图例原样上传。综合图包含构造线与矿物指示；PNG 的具体制图版次和逐项精修理由未附，实际计算依据所关联的数据文件。

新面积表按当前实际文件重算：预测使用 29×29 米像元面积，精修使用 UTM46 米制几何面积，报告各 class 面积、占比和前后变化。总面积约 2,850.879 平方千米。原 CSV 保留为历史报告。共同网格有 375,472 / 3,389,868 像元类别不同，约 11.08%，这是版本差异。

构造线保留真实空间位置并生成稳定编号；原名称、性质为空，邻近关系用于背景说明。五种蚀变指示只把值 1 记为命中；值 0 为 NoData，未检出与无观测尚不能区分。

## 为什么选这个小案例

局部为真实 6 公里范围、413 个面。保留真实类别、岩性和边界，在副本里设置三项明确标注的时代录入错误。地层名称、地区与时代字段依据类别名称和辞书补录，是演示条件属性，非师弟原图实测字段；地区细分尚未经独立野外核实。八宝山组的辞书条目给出 T3，并有地区、来源和版次定位，因此可以核对“条件地层标识与时代字段是否一致”。修改只涉及 geologic_age，验证字段一致性而非重新测年或确认真实地层归属。

小面积用于筛查候选；12 个候选的实际面积、构造距离和蚀变命中保留作为上下文。修改条件来自地层标识、地区、来源及规则，不以面积或邻近关系决定正确时代。存在新的可靠测年、区域划分差异、地层识别不确定或规则冲突时，保留复核。

本轮独立验证对象为三处八宝山组时代录入演示错误。规则表另含闹仓坚沟组，其辞书地区为青海玛多县一带（东昆仑山南坡）；局部统一地区字段是演示假设，尚未核实该地层在当前图件中的真实适用范围。该条目的“无属性问题”仅说明演示字段一致，不作为真实地层归属确认；扩展到实际闹仓对象纠正前须重新核对地区及规则版本。

两篇论文的样点尚未与当前图斑绑定，不能将其年龄直接赋给本图岩体。论文知识分别保存实测结果和作者解释。文件名 Dai 的原文第一作者为 Jian-Hua Duan，引用使用 Duan 等。具体知识整理与修订方式见 [知识说明](geology-case-knowledge-20261012.md)。

## 操作过程

1. 选择“地质逻辑推理”项目，在成果展示查看原预测、人工精修、综合图和新面积表。成果详情提供实际关联数据入口。
2. 在“智能科研体验”选择“真实地质图件 · 地层时代一致性纠偏”，点击“开始体验”。自然语言任务进入独立智能体会话。
3. 智能体匹配局部初图、真实空间背景及辞书规则，检索专家知识。必要信息缺失时在对话中提出问题，用户回答后继续解析。
4. 检查算法输出真实问题清单和位置；模型引用实际清单与知识，逐项提出允许的时代编辑计划。编辑算子再核对原值、新值、来源、地区、内容签名和对象上限，生成新图。
5. 复查使用上一步真实新图作为输入。对话显示发现、知识依据、调用原因、修改内容和复核统计。计算任务、参数、算法版本、知识修订及分析持久保存。
6. 完成后打开地理工作台，对照原图、问题位置和修改图，点击对象查看原值、新值、原因和来源。成果入库保留实际任务关联。

科研工作流保留手动资料角色与算法参数设置。每轮编辑默认最多 5 个对象，上限 10；筛查面积默认 200,000 平方米，只影响提示。工作投影依据真实图件为 EPSG:32646，平台导入的统一地理坐标由算法转换后检查。

## 实际验证范围

独立算法计算已完成检查、编辑和复核：三项 J3→T3，410 个未修改面以及全部原几何、类别和其他属性保持；复查零剩余问题。与未设错副本的独立对照全部原属性恢复。人工精修与未设错参考、设错清单仅用于选案和独立验收，未进入模型、检索或算子输入。

局部与人工精修的分类相似度约 78.48%，时代纠偏前后保持相同。本案例验证时代属性一致性链条，岩性分类精度与人工精修接近程度分别评价。

资料、凭据、知识原文包、面积表和计算产物保存于独立数据目录；Git 记录代码及必要文本。平台试运行、模型链路和服务器验收结果在交付时按实际回执补充。
