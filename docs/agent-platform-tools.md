# 智能体平台展示工具

在“智能体 → 科研智能体”选择当前项目后，可以要求“把五龙沟-海德乌拉_岩性识别按真实岩性类别配色，放到地理工作台”。模型搜索授权资料、读取类别、选择配色，成功后回答下方出现“在地理工作台查看”。按钮在新页面加载个人工程；工程列表可再次打开。

## 工具及边界

| 工具 | 参数 | 实际操作 |
| --- | --- | --- |
| `get_map_data_profile` | `resourceId`，可选矢量 `field` 或栅格 `band` | 只读字段、范围、真实类别及数量，返回完整性标识 |
| `prepare_map_workspace` | `resourceIds`，可选 `styles`、`name` | 新建本人的私有引用工程，保存图层、视角及配色 |
| `get_platform_link` | `page=map/resources/compute/knowledge` | 返回绑定当前项目的站内入口按钮 |

样式支持矢量单色和完整类别配色，以及分类栅格颜色表。分类前必须读取本轮实际概况；类别不完整、遗漏或重复会拒绝保存。配色统一调用 `result_colors.category_style`，和逻辑推理共用匹配、标准色锁定、色差、对比及补色规则。矢量 `mode=reference,field=实际字段` 直接采用统一规则，无需模型重复输出整张色表；`unique` 可以建议未知类别颜色，但不能覆盖色表原色。原表允许的同色类别保留，以图例名称区分。连续栅格和超出类别读取预算的资料可沿用已有显示方案。整数0不自动当作NoData，以实际掩膜和类别含义为准。

岩性色值只在 `lithology_colors.json` 维护，蚀变色值只在 `alteration_colors.json` 维护；`result_color_library.json` 只保存这些条目的名称、别名、来源索引，不再重复保存色值。精确单元名称优先于宽泛岩类匹配，模型不会为区分类别随意修改原表颜色。修改唯一来源后，逻辑推理、通用智能体和输入展示读取同一规则；已绑定工程与成果详情在刷新或重新打开时采用当前修订，无需重新计算或调用模型。栅格使用新颜色表的后台缓存，不在浏览器着色；普通未绑定的手工配色工程保持用户设置。

矢量类别查询最多5秒、96类；分类栅格最多400万显示像元、96类。一次最多5层，且受策略资源数上限（默认3）、跨资源开关及本轮手选范围约束。配色只影响新工程；资源名称、原始属性、几何、GPKG、TIFF及目录默认样式不变。工具不接收文件路径、任意SQL、代码或权限参数。

## 授权与持久化

每次调用重验当前项目、用户、资料ACL、active/ready及普通业务数据资格；内部工作副本、评价资料和未授权历史成果不能借此访问。读取概况需要该类图层加载权限；保存需要个人工程新增/查看权限，自定义配色另需符号化权限。后台可独立关闭地图展示工具，不影响现有计算算子开关。

工程以当前用户为owner，不自动共享，不覆盖既有工程；同一运行的相同请求幂等返回原工程。工程保存数据引用及样式，不保存原始GeoJSON或属性行。资料修订变化需要重新读取概况；按钮序列化及地图加载均重新检查访问权。栅格颜色表通过已有后台异步渲染生成PNG/XYZ，浏览器只加载图片。

“地图已准备”表示真实工程保存成功。用户点击按钮才加载页面，不会宣称已代用户控制浏览器。工具日志保留真实调用及证据，地图操作不会附加无关旧计算任务状态。
