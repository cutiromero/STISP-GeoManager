# 互花米草分布解译

## 输入与方法

“陆地生态系统风险评估预警”项目使用已登记的202503、202508、202512三幅16波段Float32原始影像，按月份及固定波段顺序组成48个特征，执行一次随机森林识别。模型使用交付的Random_Forest_model.pkl，目标类别为1，背景为0，保留模型predict分类规则。

16个波段依次为B1、B2、B3、B4、B5、B6、B7、B8、B8A、B9、B11、B12、NDVI、NDWI、NBR、EVI。指数和输入值不在推理时重新计算或归一化。三个季节须为不同资源、相同原始网格，全部48特征共同有效的像元参与识别。

科学原件为EPSG:4326，资源的EPSG:3857表示用于地图。发布端口通过raster.window声明研究区四个经纬度参数。预检按解码窗口预算检查，执行时固定源网格窗口；窗口参与输入版本身份，缓存不混用其他研究区。单次研究区最多4,194,304像元，大范围可分研究区处理。

CPU模型执行使用现有解释器和已验证的scikit-learn 1.9.1，保留实际环境版本与权重摘要。加载交付1.7.2权重的版本提示保存在验证记录中。模型、依赖或执行配置改变后须重新试运行和发布。网站进程组织任务，计算中心沿用已有队列、取消、时限、内存和入库控制。

## 成果与统计

分类GeoTIFF保留原始窗口坐标，1为互花米草、0为有效非目标、255为无效区；目标色为#65D8A4，背景和无效区透明，分类显示及概览采用最近邻。

目标概率单独输出为Float32、范围0至1，NoData为-9999。统计包含WGS84椭球面积、共同有效面积、有效区内占比和8连通斑块数。统计在原始网格进行，斑块在有界研究区内跨块合并，不用Web Mercator显示像元计算面积。

08月B4/B3/B2生成独立真彩色窗口供原图对比；分位显示拉伸不进入模型输入。分类、概率和统计属于正式交付，显示预览与处理依据保留在任务记录。已有UNet历史分布面仍按外部历史成果展示，不自动作为核验标准或新计算结果。

## 业务流与大屏

项目专用“互花米草分布解译”使用同一主执行者推进：确认研究区与资料、核对三季节输入、RF解译与成果准备、核验分布统计、整理大屏成果、完成交付。三个季节作为一个组合提交一个计算任务，模型计算完成后的入库恢复不重跑已成功计算。

大屏沿用[公共展示框架](monitoring-shared-presentation.md)，六张卡片分别为研究区与成果、解译任务、分布统计、分布与显示、方法与输入、成果说明。共用来源选择、任务抽屉、原图/分类/叠加/卷帘地图和图外状态区；独立统计内容不使用地表覆盖六类分类。

“开始解译”默认绑定三季节资料，选择WGS84研究区后提交。任务与智能体使用同一记录；“处理记录”查看已有运行，当前任务身份保持独立。本次、历史、上传和标准成果按公共来源协议选择。配套概率、统计和真彩色预览通过同一实际计算任务关联，并再次核对资源权限。

任务状态键包含账号、项目、场景和业务流定义。页面隐藏或等待人工时停止定时读取，任务卡与抽屉共用读取。地图显示更新使用现有成果和公共平滑切换，下载使用资源实际关联的栅格数据集。

## 准备与登记

1. 用项目Python运行tools/spartina/prepare.py，检查现有RF环境和模型摘要。
2. 运行tools/spartina/configure.py，将只读模型资产、项目与计算预算写入正式TOML的compute.ml，保留既有环境和GPU配置。
3. 通过标准full发布及tools/spartina/candidate_check.py完成真实RF、分类图例、配套入库和项目隔离验收。
4. 使用register_spartina的operator、trial、publish三个阶段完成正式登记。试运行默认绑定现有三季节资源及长江口研究区；输入或区域可通过命令显式指定。
5. 从正式站大屏启动业务流，检查实际分类、统计、来源选择、原图对比和下载。

单通道UNet仍使用独立的输入及科学预处理口径，未作为本RF流程的替代输入。
