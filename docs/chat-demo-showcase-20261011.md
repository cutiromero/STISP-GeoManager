# 自然语言科研案例体验

成果展示页的“智能科研体验”提供生态调查与地质纠偏两个入口。目录按当前用户的项目和资料权限生成，点击“开始体验”后切换到对应项目，在智能体中创建独立会话并发送自然语言任务。入口请求使用幂等键，刷新从服务器恢复会话与实际工作流。

## 页面与操作

1. 进入成果展示，选择一个已就绪的案例，点击“开始体验”。
2. 智能体解析任务，按明确角色匹配资料和已发布算法。案例使用标注的模拟资料与样例参数，实际执行计算。
3. 信息明确时自动开始初始计划。必要的澄清在对话中显示，可以选择选项、填入数值或用文字回答；答案重新交给模型解析。
4. 对话持续展示公开的判断说明、实际引用、计算进度和最终成果。采用的资料与设置收在可展开摘要中。
5. 质量需要审核时，查看实际计算报告与候选资料，选择“审核并继续”或停止。初始计划的自动执行授权不代替结果质量审核。
6. 完成后点击“在地理工作台对比成果图层”，查看计算地图。成果保存在当前项目的数据资源中，会话和判断可在刷新后恢复。

“智能体 → 科研工作流”保留完整参数设置，供手动选择输入和配置科研流程。

## 两个案例

生态任务先处理前后两期影像，再计算共同有效像元的植被变化，结合调查分区与初始观测形成调查建议。覆盖不足的分区单列为优先补资料。完成后可继续输入“使用补充观测更新调查建议”，模型将本会话已经成功的分析与新增观测关联，复用前次变化成果，只重算受新证据影响的调查排序。报告呈现新增证据和实际统计对判断的影响。

地质任务使用模拟初始填图、调查记录和允许操作的小规则集，先检查问题，再进行几何处理、受约束属性纠正和最终复查。原图、修改图及修改依据保存在同一工作流中。参考地图和设错清单独立用于验证，没有进入模型或检查、编辑算法的输入。

## 持久记录与调用范围

- 聊天运行保存独立的科研意图、问题、输入角色、参数、修订及真实工作流关联，不以回复文字代替任务提交记录。
- 新一轮执行新的任务使用新的请求起点；澄清答案和进度查询继续原任务。生态补证据生成关联的新工作流。
- 数据、算法、知识的手选范围作为调用边界，跨轮历史也检查同样的范围。资料变更、撤权或算法停用后重新核验。
- 已发布算法版本在计划中冻结，步骤将真实输出接成后续输入。模型的公开判断对应当前实际资料、知识修订和计算结果。
- 任务解析使用授权目录中固定的输入角色键。JSON、角色或参数校验失败时，系统提供具体错误和完整目录，允许模型纠正一次；每次请求、响应和校验结果都保存为内部审核记录。网络、权限及取消异常直接停止。
- JSON/FK迁移仅添加聊天科研关联，不更改旧会话、数据资源或计算结果。
