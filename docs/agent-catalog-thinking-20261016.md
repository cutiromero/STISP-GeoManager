# 智能体目录统计、思考输出与项目入口

## 目录统计

数据智能体新增 `summarize_resource_catalog`，在当前项目、当前用户可见范围和手选数据范围内，由数据库直接汇总数量、数据类型和大小。分类依据 `is_compute_result`，避免从名称或说明猜测来源。非计算数据称为“上传/登记数据”：平台历史登记数据也属于这一类。

`search_resources` 返回 `total`、`count`、`offset`、`nextOffset`、明确分类和同范围汇总。默认每页50项，长说明会按模型上下文保护自动缩小一页；继续使用 `nextOffset` 可以取完目录。原先固定前20项且没有后续入口的限制已移除。统计数量与清单分页分别处理。

## 深度思考

真实Qwen服务对照发现：强制 `response_format=json_object` 时直接生成JSON，不返回思考标签；保留深度模式并移除该约束后，服务返回思考标签。深度工具模式使用提示词约定格式，服务返回的工具指令仍由后端严格解析、校验权限及参数后执行。快速模式保留JSON约束。

模型实际返回的思考片段按事件保存，刷新后恢复。服务没有返回片段时，页面准确说明这一情况，不生成替代片段。

## 后台参数

后台移除工具步骤、详细资源数、判断与算子次数、运行时长、输出及窗口等设置中的固定校验上界，管理员可按实际模型和主机能力配置。每日次数、工具步骤、详细资源数允许0，含义为不设该项额度。手选数据和算法不再限制为3项。保留项目权限、数据隐私、注册工具与参数校验、实际模型窗口、单附件大小及服务并发保护。

## 成果展示

科研Demo入口依据后端真实项目归属和当前授权项目过滤。地质修正留在逻辑推理项目，生态评估留在干旱区项目；进入Demo保持当前项目。公开和其他项目不再显示跨项目Demo入口。

## 删除保护调查（本次未改动）

删除保护同时检查计算输入、入库关联、成果、地图工程、科研工作流与处理中任务。计算和工作流关联未按状态区分，所以已结束的历史引用也会阻止删除。这条提示不能说明工作仍在运行。

科研工作流与聊天记录独立，保存输入、计划、步骤、审核、输出及保存点，用于恢复和复查。当前没有普通用户可操作的“解除工作流引用”入口，删除聊天不会解除引用。本次保持删除规则和业务数据不变。

## 交互能力边界

科研流程支持模型澄清、选项/文本/数字/资源表单、审核通过与拒绝、审核意见、选择部分地质建议、暂停继续及刷新恢复。通用聊天支持多轮追问和算法参数卡。执行中随时插话调整计划、任意任务统一结构化人工交互仍需后续开发。暂停在保存点停止后续步骤，已提交的计算可能继续完成。
