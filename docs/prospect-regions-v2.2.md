# 平滑连通远景区算子2.2

`geology-multi-prospect@2.2.0`将修正后岩性、构造、五类蚀变矿物及有效权重综合为连续支持场。默认收敛尺度与已审阅的五龙沟—海德乌拉方案一致，使用50米分析格网和100米支持场平滑尺度。新版本登记在计算中心，由正常逻辑推理流程选择最近发布且获授权的版本。

边界直接从平滑连续场提取。半格插值只处理可能成区的范围及必要邻格，复用原连续场数值，减少完整格网坐标矩阵的内存分配。一个自然连通支持带对应一个远景区；相交或接触的支持面先合并，真实断开的支持带分别编号，区域之间无重叠。面积较大的连通区域整体保留并记录提示。默认按有效支持面积、核心面积和平均支持度选择最多8区；最小区域1平方公里，最小核心0.05平方公里。

强核心使用原地质规则。外围的蚀变、构造、岩性支持权重分别45%、40%、15%。零权重和剔除资料不提供正证据，缺测仍为无观测。支持度未作矿点标定，不表示有矿概率。输出包括修正后远景区、强核心、逐区实测依据、统计与红黄蓝渐变支持度热力图。

## 阶段性结果查看

逻辑推理进入计算阶段后即可打开对比页，无需等待全流程与最终报告完成。页面展示当前已生成的资料、疑点与成果，处理中显示阶段性结果提示。后续阶段输出后，点击刷新结果或刷新浏览器重新读取最新图层；显式刷新会清除页面图层读取缓存，保持当前查看位置与章节。尚未生成的远景区不显示成已完成结果。

## 正常逻辑推理中的行为

从智能体启动新的逻辑推理任务，完成现有输入和必要审批后，远景区阶段使用2.2.0默认收敛尺度。远景区格网参数为`prospect_grid_resolution_m`，与前置检查的通用网格参数独立，默认50米。输出遵循现有修正后结果协议，报告读取完整逐区汇总，地图显示修正后的区域边界与连续热力图。

地图协议按算子声明的输出能力识别：同时声明`after_zones`及`prospect_support`且无`before_zones`即采用修正后单幅找矿结果。后续小版本沿用相同输出协议，无需再增加版本字符串判断。

历史任务继续保留其冻结的算法版本、方案与输出。新任务默认选择最近发布版本；已有固定算法范围的会话继续遵循其授权范围。原始登记数据与知识版本保持原样。

## 验证与发布范围

本机真实修正后输入的2.2输出与已审阅方案8区、79.260595平方公里的几何完全一致，逐区依据符合平台schema_version=2并能用于完整汇总和模型报告。相同算法核心已在服务器native runner验证为8区、79.263303平方公里，两两重叠面积0；跨平台边缘差异记录在候选验收说明中。

正式发布使用独立候选及生产目录、原有前端静态构建、平台现有版本发布接口和新版本回执。平台API契约、权限、原始数据路径及前端栅格渲染架构保持原样。新算子登记与发布增加独立版本，不覆盖旧包；验证任务与会话单独标识并保留可追溯记录。
