# MH-workflow历史与项目访问

代码版本0.1.53；上线状态以对应提交正式回执为准。

## 加载与恢复

- 面板关闭时不读取场景、历史或计算目录，停止面板轮询；后台计算继续运行。
- 首次打开只读取当前项目的场景名称，先显示“请选择研究场景”。
- 选择场景后读取该场景预设、所需目录及本人历史摘要，分别显示加载提示。
- 历史按当前账号、当前项目、当前场景分页，支持继续加载；索引不包含完整计划、知识证据和工具结果。
- 选择某条历史后才读取完整详情，并再次核对原有访问权限。历史目标在索引中显示前300字，详情保留完整目标。
- 当前浏览器会话按用户、项目保存已选场景及明确选择或创建的任务标识。重新打开或刷新后恢复该任务，已知运行状态保留。
- 没有明确任务指针时，仅列历史摘要，不自动展开已完成任务。用户自行选择继续查看或开始新任务。

工作流本身保存在服务器，与普通聊天记录分别管理。相同账号换电脑后，选择同一项目和场景即可看到自己的历史，再选择恢复；当前浏览器的选中指针不跨电脑同步。其他账号看到自己的记录，项目提供的场景预设可以共同使用，不会自动继承另一人的运行、批准或聊天。

## 性能依据

本次在0.1.52正式站只读测量：QA账号2的逻辑推理项目历史19条，完整响应13,769,708字节，公网约24—25秒；服务器回环约0.82秒。字段体积主要来自计划、步骤和证据。服务器当时未见CPU或内存耗尽。该测量是验收账号的数据，szf本人当时没有科研工作流历史，不能直接作为szf现场耗时。

首开还会读取全部数据候选，273条需要6次串行请求，测得约2.53秒。新流程将这些请求推迟到选定场景，移除关闭时的完整历史请求。浏览器硬件、版本、网络及所选结果复杂度仍会影响交互；本次优化针对已经确认的请求时机、载荷和服务端逐历史依赖检查。

完整历史详情可能包含较大的地图/工具结果，用户主动选择时仍需传输，界面提供加载与错误提示。索引和完整详情各自保持权限边界。

## 仅允许指定项目

入口：后台项目标签管理 → 分配用户标签 → 选择用户。

默认开启“允许访问公开项目”，旧用户和游客继续按原方式访问公开。
若需要该账号仅访问逻辑推理：关闭此开关，只分配逻辑推理项目并保存。

关闭公开访问时至少保留一个已启用的分配项目；系统将首个授权项目作为默认项目，不再强制回到公开。
超级管理员保留全部项目管理权限。该设置通过后端约束资源、历史、知识、分享及后台运行任务，并保留原有数据记录。

游客仍可访问公开资料，因此本开关限定的是登录账号工作范围。需要保密的资料存入受限项目；共享算法登记继续可以复用，执行数据始终来自授权项目。科普、团队等独立公共内容沿用既有规则。
