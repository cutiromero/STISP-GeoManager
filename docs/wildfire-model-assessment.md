# 野火权重与预处理方案对比

## 结论与接入方式

五份权重均与U-Net++ / EfficientNet-B5的11输入通道、1输出通道结构严格匹配。首层统计和真实数据对比支持“连续变量按有效值标准化、缺测填−1、陆海掩膜保留原值”的重建方案。人口密度的有限NoData哨兵必须在计算均值、标准差和模型输入前转换为缺测。

w1/w2/w4/w8/w16代表不同权重，不是相同文件的重复命名。输入通道数均为11，没有随w增长，因而不支持把它们直接解释为按通道拼接的多期输入。现有材料不能唯一确定它们对应预测提前期、目标汇总窗口还是另一种训练设置。大屏主业务流使用有实际日期和单位的历史观测；这组网络目前用于模型试算与方法对比。

## 权重与源码依据

- 五份checkpoint均保存986个状态项，首层卷积为`(48, 11, 3, 3)`，严格加载没有缺失或多余参数。
- 五份文件SHA-256各不相同；训练记录均为epoch 49、global_step 36850，Lightning 2.6.1，Adam学习率0.0001。
- checkpoint没有hyper_parameters或输入标准化参数。ModelCheckpoint未配置验证指标监控，保存的是训练末期文件，不能据此视为验证集最优版本。
- 提供的Unet类使用U-Net++ / EfficientNet-B5。FirePredict和ClimaFire中的lead_times属于另一类网络，不能用来解释这五份U-Net++权重的预测时效。

## 预处理推测与验证

按提供源码中的11变量顺序比较：mslp、tp、vpd、sst、t2m_mean、ssrd、swvl1、lst_day、ndvi、pop_dens、lsm。该顺序是待验证的输入映射假设；首层卷积和BatchNorm反推的通道均值，与对应变量的缺测比例及陆海掩膜均值相符，为该映射提供了支持。

标准化统计使用2001–2016年内46个抽样时期、每隔16个原始时间索引取一期，经纬方向每隔8个格网抽样。只使用有效值拟合连续变量均值和标准差，保持零值。它是明确记录的重建统计量，并非从原训练程序恢复的精确参数。

pop_dens的原始fill_value和missing_value为`-3.3999999521443642e38`。按此掩膜后，抽样缺测比例为74.14%，有效均值52.07、标准差337.74人/km²；将哨兵纳入统计会使输入分布失真。sst、swvl1、lst_day、ndvi的抽样缺测比例分别约34.97%、65.91%、67.09%、78.13%，与首层反推的负均值偏移一致。lsm保持0–1。

以下为五份权重的首层矩偏差平均值，越小表示与训练保存的首层统计越接近；该量不表示预测准确率。

| 方案 | 首层矩偏差 |
| --- | ---: |
| raw_zero | 7.56558e+08 |
| standard_zero | 0.555594 |
| standard_minus_one | 0.0134773 |
| minmax_zero | 6.70747 |
| minmax_minus_one | 2.18467 |

变量标准化后填−1的偏差约为填0方案的1/41。极值缩放和未经标准化的输入均与权重统计明显不符。

## 真实数据对比

使用澳大利亚、巴西、南部非洲三个有界区域，每个区域取2018、2019、2020三个实际时期。2018–2019用于探索，2020作为本轮对比的留出年份单独报告。原模型的训练划分未提供，不能据此保证2020未参与原模型训练。网络输入为128×160或128×192的0.25度格网，保持原网格和通道顺序，使用CPU真实前向推理。

目标对比包含当期、未来1/2/4/8/16个原始周期的单期GWIS正火烧面积，以及未来1/2/4/8/16期内任一期有火。评分限于陆地且目标观测有效的格网；持续性基线使用同一掩膜和当前GWIS有火状态。原始周期按时间轴变化，不能一律称为8天，更不能直接称为日历周。

下表固定“权重wN对应未来N个原始周期的单期目标”这一假设，对2020年三个区域、五份权重的15个组合取宏平均。ROC-AUC和AP越高越好，Brier越低越好；平均正样本比例为0.1226。

| 方案 | ROC-AUC | AP | Brier |
| --- | ---: | ---: | ---: |
| standard_minus_one | 0.6536 | 0.1855 | 0.1140 |
| standard_zero | 0.6503 | 0.1811 | 0.1130 |
| minmax_minus_one | 0.5365 | 0.1237 | 0.1215 |
| persistence | 0.6234 | 0.2340 | 0.1278 |

标准化后填−1的排序指标略优于填0和极值缩放，但其AP低于持续性基线，Brier与ROC-AUC则较好。不同指标给出的结论不一致，且各权重在候选目标期上的最优位置不一致，因此这些样本不足以唯一确认wN时效，也不足以给出校准后的火灾发生概率或正式预警阈值。局地裁剪边缘、区域差异和空间相关性也会影响评分。
