# 智能体历史读取与执行授权

历史读取检查当前用户、项目、资源隐私、知识可见范围和功能权限，返回已保存的提问、回答、模型实际思考片段和工具证据。资料改名、补充描述或知识修订后，读取原历史使用保存的快照，不重新执行旧计划，不改写旧证据。

`authorize_run`、`authorize_demo`和相关序列化的内部`history=True`分支用于读取；执行、批准、恢复计算和新报告生成继续使用默认严格分支，核对输入及输出版本、知识修订和获批方案。参数卡处于collecting、ready或blocked时，仍提供当前可访问的数据候选；已结束的计算不再重复读取候选文件。

对象仍存在时继续检查当前访问权限。对象缺失时，只有平台正式删除流程保存的凭据、终态记录、原所属项目、数据类型和owner_only权限均匹配，才允许保留相应历史。缺失对象或PermissionDenied本身不构成历史授权，执行分支明确拒绝使用已删除数据。

工作流列表、详情、派生聊天和前次生态分析链使用同一读取路径。结果仍存在时，历史授权继续核对真实ComputeImport、任务与输出校验和关系，仅不将资源元信息revision变化当作撤权。

已经保存的报告，prepare、在线预览和下载读取原文件并检查当前访问；首次生成与入库继续检查执行依据。知识撤下、资源转为他人私有、项目成员资格撤回、数据类型或智能体功能权限关闭时，历史仍拒绝访问。

回归入口：`test_agent_history_access.py`、`test_agent_deleted_history.py`、`test_agent_knowledge_bridge.py`和`test_workflow_reports.py`。本次没有新增或变更API字段。
