# 退出体验与工程隐私（2026-11-04）

本轮基于正式 0.1.57，更新至 0.1.58。

## 页面变化

- 主动退出立即返回登录页；清除当前身份和租约，后台完成服务器退出及本地图层缓存清理。
- 登录页移除登录失效黄条。会话鉴权、关闭页面后的登录生命周期和同账号过期后恢复原页继续保留。
- 登录页不读取项目列表。已取消或属于旧身份的项目请求不显示失败；真实项目网络异常仍显示局部重试。
- 退出后立即登录串行完成认证请求；退出请求最长等待10秒。旧心跳和恢复响应不能清除新登录状态。
- 工程编辑说明改为默认私有，其他人接受分享后只读。工程管理的所属项目列表示归属，不表示全体成员可见。

## 工程授权

创建者维护自己的工程，接受邀请的用户只读；同项目成员、游客及普通平台管理员不自动获权。超级管理员保留当前项目管理能力。

该规则统一应用于列表、搜索、详情、快照、后台管理和直接ID访问。未获授权的工程ID返回404。分享接受前、被拒绝时不授权；接受后每次重验项目、双方和底层数据权限。

专题发布仍按专题规则，分享专题不额外开放来源私人工程。未删除历史工程、聊天或科研数据；本轮无数据库迁移。历史工程按已有owner适用新规则，旧角色元数据不再授予工程访问。
