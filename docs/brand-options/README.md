SVG XML、浏览器资源加载、预选交互及手机宽度下无横向溢出已检查。实际截图保存在被 Git 忽略的 `.runtime/brand-options/`。本轮仅保存候选文本源文件；没有修改 API、权限、数据路径或栅格渲染。

## 用户选定后继续

1. 根据最终选择替换网页导航、登录页及浏览器 favicon，旧图标仍保留于 Git 历史。
2. 验证本机页面与生产构建中的图标路径；更新前后端版本及 CHANGELOG。
3. 通过交接信息尝试服务器只读连接；若现有认证失效，再向用户索取更新的凭据，凭据不进入 Git。
4. 核对服务器当前版本和变化。仅替换图标时避免把本机空数据库、开发配置或未经核对的其他代码覆盖服务器。
5. 冻结发布提交，保存旧版本与恢复点，完成候选验收、生产切换及回执。
6. 将同一已验收版本同步至当前私有 GitHub 仓库，记录服务器与 GitHub 对应提交。

注意：当前 GitHub 是凭据清理后新建的提交历史，与师兄生产版本的祖先链不同；部署必须核对文件树差异及完整 SHA，不根据标签名称猜测版本一致。
