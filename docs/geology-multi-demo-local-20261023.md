# 海德乌拉地质综合推理：本地演示说明

日期：2026-10-23。此次仅本地集成，保留已有地质及生态 Demo，服务器未更新。

## 从哪里进入

访问 `http://127.0.0.1:5173/`，登录后选择“地质逻辑推理”项目。

- 成果展示 → 海德乌拉地质综合推理 → 综合演示，进入科研智能体。
- 三个分段入口分别为“岩性检查与纠偏”“构造复核与交汇重建”“蚀变判别与找矿远景圈定”。
- 科研智能体 → MH-workflow 也可选择新场景，核对九种角色资料、分段和参数，然后生成计划。
- 完成任务末尾可进入前后地图，预览、下载或入库 Markdown 检查报告，并下载真实数据和 CSV。

综合入口串起全流程。岩性入口止于岩性修改及复核；构造入口增加关系重建；蚀变入口加入综合远景区比较。各入口保存当次选用的上游资料版本，展示实际运行结果。

## 演示怎样操作

1. 选择综合入口，确认采用本次演示资料。岩性与构造输入标“模拟识别输入（演示）”，五类矿物标“遥感矿物识别结果（演示案例）”。
2. 系统读取资料和本案例试用知识，调用“三要素检查与建议”。每项建议可查看实际测量、命中规则、条件和例外。
3. 在“等待用户批准”处，勾选少量建议。建议讲两处名称代号不一致、一条构造复核、一个矿物背景干扰；也可全部保留继续。
4. 点击批准后，系统仅执行所选对象及动作，形成新版本，再真实复核、重建交汇、比较远景区。
5. 打开前后地图：点击问题定位，查看处理前后；查看几何交汇实心点、推测交汇空心点及 A/B 远景区。密集矿物与疑点图层按需勾选。
6. 展示末尾检查报告与统计文件。刷新或切换会话后，可恢复原任务及批准状态。

如需重复演示，从入口重新发起任务并使用同一组预设输入；平台会保留各次任务和新成果。已有任务不会覆盖原包或输入文件。

## 智能体、知识与算法各做什么

智能体根据当次数据、工具返回和知识引用组织检查说明与建议；流程阶段由 MH-workflow 编排。知识提供条件、例外、阈值和名称代号映射。四类算法负责实际测量、获批修改、关系重建与前后远景区计算。

当前本机只配置 `mock-local` 模拟模型。因此，本次验证包括模拟解析/判断、持久交互及真实 GIS 计算；真实大模型的任务理解和专业判断仍待配置模型后另测。模拟服务不会提供独立地质研究结论。

17 条规则保持 draft，界面注明“本案例试用”。只有当前项目、当前场景显式绑定的规则及修订可被服务端读取，普通 draft 检索权限保持原状。34 个归一代号对应 38 种名称，别名映射保持多对一关系。

## 与交付参考实现的调整

- 检查、建议、批准和执行分开；未批准项保留，待核查、降权及暂不参与分别记录。
- S-02 使用构造落在边界缓冲内的长度占构造总长的比例；矿物背景按类别汇总交叠面积。
- 实际重投影、研究区掩膜、前后相同网格和参数，分级与依据链使用同一证据表达式。
- 每个任务独立目录，支持空的可选结果。运行输入去除注入标记和可透露类型的编号。
- 原包、内部参照和评价清单保持独立；交付 PNG 仅标作“交付参考结果”，不充当平台计算图。
- 1.0.0 试运行发现表格导入规范化展示文本尾部空白，导致批准比对失败。1.0.1 仅规范化这些展示文本；对象、动作、测量、几何、版本和快照继续严格核验，失败记录保留。
