# 业务流独立审核的证据范围

业务节点审核保留完整来源摘要、分组计数和实际输出引用，模型只核对当前提供的证据。坐标传输留在原始图件中，重复的任务质量信息使用明确来源引用；原件、计算结果和人工批准记录保持原样。

最终报告审核复用报告生成已有的完整事实投影：初检问题数、真实执行处置数、各动作数量、复查剩余数、远景分期及等级统计、实测条件和知识引用。完整且不同的任务质量记录单独提供，保留待复核状态与质量告警。批准统计按完整要素、规则、动作及矿物、岩性背景、边界等维度合计数量、面积和像元数；批准范围由原方案摘要、完整批准数量、批准集合摘要及来源输出绑定，不因整理而重新批准。

原始栅格、矢量成员及中间图件保留在已完成任务的完整输出和审计中。最终审核不重复发送这些图件的坐标、历史问题明细或重复元信息，也不重新提出数据修改。所有分组、数值范围、面积和知识条件沿用现有报告投影，不能通过任意截断文字、跳过质量检查或扩大模型额度规避预算。

候选摘要由真实决策、处置建议和完整实际结果共同计算，并复用到最终审核中。新的角色请求仍独立鉴权、检查输入版本和预算；投影不改变原批准边界，不使模型获得人工审批权限。

专业审核使用共享上下文服务的预算公式、计量缓存和整理审计。事实投影及精确引用去重后仍无法容纳的请求不发送，保留候选进入可恢复等待。审核返修仍走原执行者和原科学图，审核者没有读取未提供明细的权限，也不能要求绕过人工决定。全链路调用清单和六组保守分词审计见 `logic-agent-execution.md`；真实模型服务的tokenizer与输出质量须另行验收，桩测量不冒充真实模型用量。
