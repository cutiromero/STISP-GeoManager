# 监测任务与算子维护

## 执行与交付

- **中石油地表覆盖**：2 m、Byte、三波段 RGB、米制投影 GeoTIFF。按全影像执行，交付六类分类和面积统计。
- **互花米草**：同年 3 月、8 月、12 月三幅同网格 WGS84 Float32 GeoTIFF，固定 16 波段顺序。按共同有效全域执行，交付分类、概率和统计。
- **野火观测**：已登记 SeasFire Zarr，选择实际变量和观测期。交付原值图、分级图、统计表、序列表，结果不是风险预报。

业务流详情提供输入要求。首次使用的新资料需在当前项目入库，再由任务绑定。任务由同一个主 Agent 组织、预检和核验。可修复的格式或数据差距优先使用已发布适配算子；需要脚本衔接时走隔离和独立审核，只生成派生输入。主 Agent 不改原件、核心科学算子或已确认的观测含义；资料足够时无需再次圈选。任务完成后在数据中心按任务查看成果，可确认登记符合质量条件的监测地图。成果与原始资料的访问范围不因登记而扩大。

## 大屏展示

右侧「区域成果一览」显示当前场景各项已登记成果的观测期、关键指标和原单位。选择一项可联动地图和上方统计；只登记一项时显示观测期、登记时间及已有的来源和核验信息。大屏不显示历史版本，也不发起计算。

## 业务流和算子

科研用户可在当前项目新建、编辑业务流，或将共享通用流程复制到本项目。节点可绑定已发布算子版本、初始输入角色或上游输出；主 Agent 和节点的执行指令与审核设置随版本冻结。编辑时发布新版本，旧任务继续使用其启动快照。跨项目只读复用的共享流程不能直接编辑，启用或停用已有流程仍由超级管理员操作。

科研用户可从计算中心「新建算子」登记，或在「算子维护」修改当前项目的算子名称、分类、来源和用途。可下载模板准备 ZIP；上传、试运行、归档停用和删除仍由版本维护者操作，发布仍须具备发布权限。未发布的算子版本不能绑入业务流。

## 发布维护

在标准候选与代码发布后，使用 `publish_monitoring_workflows --actor <维护账号>` 核对三个已部署流程与现行算子；添加 `--apply` 才发布新版本。它不会重算、替换旧版或更改当前任务。

历史清理命令 `clean_legacy_compute_catalogue` 按明确的资源编号和含时区的任务结束上限预检。只有来源与唯一计算入库记录匹配、未被业务引用的副本可删除，使用 `--apply` 才执行。正式产品、任务历史、计算输入、已保存工程或其他业务保留数据不受影响。
