# 环江油田地表覆盖解译

## 输入与模型

中石油管道项目使用已登记的六幅原始RGB影像和样区边界。输入为北向上、米制投影、2米分辨率、Byte三波段GeoTIFF，长宽均至少1024像元。科学计算读取原始Albers影像；地图使用登记的显示表示。影像获取时间未知时保持空值。

`landcover-unet-infer`每幅影像执行一个计算任务。建筑、水体、耕地、林地、道路五个UNet共用已验证的`workspace`环境，严格加载交付权重，固定归一化、滑窗和后处理参数。权重作为独立只读资产，算子包只保存代码和清单；解释器、GPU范围、模型目录和资源预算来自正式TOML。GPU租约在进程间互斥，任务继承原计算中心的时限、取消、质量和入库控制。

## 分类与面积

完整解译执行全部模型，冲突按**建筑＞水体＞耕地＞林地＞道路**覆盖，剩余有效区记为裸地。专项提取仅执行所选模型，未提取区域透明。完整分类图中的某类像元不替代该模型独立的二值提取结果。

| 编码 | 类别 | 配色 |
| --- | --- | --- |
| 1 | 裸地 | `#FFD266` |
| 2 | 耕地 | `#FFFD5B` |
| 4 | 林地 | `#27C223` |
| 5 | 水体 | `#79DAFF` |
| 6 | 建筑 | `#FFB9B9` |
| 8 | 道路 | `#F31717` |
| 0 | 专项未提取区域 | 透明 |
| 255 | 无效区 | 透明 |

后处理采用8邻域，16m²小斑块阈值并保留边界目标；建筑、水体和耕地填补不超过16m²的孔洞。林地和道路不补孔，道路不使用长度筛选。

合成时累计最终互斥类别的像元数，面积按原始网格的4m²像元计算，占比使用有效区面积。样区分别统计，重叠样区的面积不能直接相加作为研究区总面积。分类入库沿用实际图例、透明值和最近邻重采样，下载保留原始网格。

## 业务流与展示

项目专用业务流“环江油田地表覆盖解译”依次确认资料、核对输入、执行解译与入库、核验统计、整理展示、交付成果。多个样区必须都有真实成功成果才能结束解译目标。入库失败保留已完成计算，恢复时只重试原入库；暂停、停止和权限变化在后续执行边界生效。

大屏采用现有生态大屏框架与六张卡片，支持样区选择、分类成果版本、原图、分类、叠加、卷帘、类别显示和成果下载。“开始解译”使用现有业务流启动组件；任务卡和抽屉共用当前任务读取，页面隐藏或等待人工时停止定时读取。任务完成刷新成果列表并定位最新成果。当前样区尚无分类成果时显示原图，分类、叠加和卷帘在该样区成果就绪后启用。

“处理记录”读取本人当前项目的业务流记录。“在智能体中打开”定位同一会话和运行记录，继续使用智能体模块。业务流与成果按项目隔离；该流程仅在中石油管道项目登记。

## 缓存与部署

输入版本沿用原件摘要和权限检查，五个模型共用一次冻结输入。阶段缓存限定当前任务及其显式重试链，绑定输入、权重、代码、归一化、后处理参数和运行环境摘要，复用前检查文件完整性。独立新任务执行实际模型计算。阶段缓存按临时输出保留期清理，活动任务及重试链受保护。地图类别显示、配色、卷帘和统计读取使用已有成果。

使用`tools/landcover/prepare.py`核验并准备资产，`configure.py`配置受控GPU运行；网站通过标准`full`发布和候选验收。`register_landcover`依次执行`operator`、真实资源`trial`、`publish`，复用计算中心的试运行发布门禁，登记私有业务流并启用项目大屏。
