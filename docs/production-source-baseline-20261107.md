正式 Web、compute_worker、agent_worker、workflow_worker 必须加载同一冻结提交的 code 目录；启动器 APP_ROOT 与 WORKER_APP_ROOT 也必须指向该目录。发布控制器按四个角色切换前的实际工作目录、命令和 PID 固定身份，不能依据过时的启动器变量判断正在运行的 worker。
