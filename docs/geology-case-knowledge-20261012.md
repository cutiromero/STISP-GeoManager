# 真实地质材料知识补充

本批次服务于东昆仑真实图件的术语解释和小范围地质纠偏。复用现有 `KnowledgeEntry`、`KnowledgeRevision`、知识分区与检索界面，全部条目属于“遥感地质填图逻辑推理”。知识包保存在科研数据目录；代码仓库保存导入命令、测试和说明。

## 材料与知识范围

从本地可解析的 99,518 条 CGL 术语中筛选 45 条：图件出现的地层名称、岩性、构造、地层单位及五种矿物指示相关术语。另从两篇原 PDF 整理 11 条知识，加 1 条八宝山组时代标注一致性的应用条件，共 57 条。

| 知识类型 | 保存内容 | 主要用途 |
| --- | --- | --- |
| 辞书定义 | 原 `definitions` 释义、辞书署名、CGL ID、URL、条目编码、采集时间；地层条目附分布、原时代及版本差别 | 岩性和地层解释、名称与时代复核 |
| 论文实测 | 年龄、误差、样品号、方法及相应野外/显微观察，附 PDF 页序与印刷页码 | 检查已有描述、支持具体样点判断 |
| 作者解释 | 岩体划分、控矿关系、成因解释及“可能多期成矿”假说 | 提出检查方向和调查建议 |
| 纠偏适用条件 | 八宝山组名称—T3 标注一致性；明确地区、资料口径、允许编辑字段及例外 | 真实地图副本上的时代属性演示纠偏 |

术语按记录的 `name` 精确筛选，并使用 `definitions` 内的署名。部分采集缓存的 `attributes.名称` 聚合了无关词条，因此没有直接把该字段全部当成别名。多辞书合并署名按原记录保留；未逐一核验纸质辞书。缺少可归属释义的条目不用于发布知识。

## 导入与修订

命令 `import_geology_case_knowledge` 接收外置、已审阅的 JSON 知识包：`schemaVersion=1`、`batch`、`entries`。条目复用现有字段，另有稳定 `seedKey`。显式提供目标 `--project-id` 和维护账号 `--user-id`，支持 `--dry-run`。

```text
python manage.py import_geology_case_knowledge --bundle <knowledge_bundle.json> --project-id <逻辑推理项目ID> --user-id <维护账号ID> --dry-run
python manage.py import_geology_case_knowledge --bundle <knowledge_bundle.json> --project-id <逻辑推理项目ID> --user-id <维护账号ID>
```

导入前验证项目启用状态、账号有效性、项目访问与知识维护权限，整批事务处理。按稳定键或“对象＋谓词＋同一组适用条件”匹配旧条目：

- 内容相同则保留，重复运行不新增条目、修订或审计记录。
- 同条件的新材料更新当前断言和例外；更新前保存旧版快照，新版保存 `KnowledgeRevision`。旧断言的额外来源以“历史修订来源”标记，不混为当前断言的支持证据。
- 同范围重复来源合并、别名合并；不同地区、知识类型、时期或研究解释分开保存，并输出 `scopeOverlaps` 供材料核对。
- 同一稳定键的适用条件改变时要求使用新键，避免把原地区知识悄悄改成其他地区。

项目来源权限沿用平台既有边界。本命令不会改动知识文档库、WeKnora 配置或其他项目条目；要供更多项目使用，由有权限的维护者将审阅批次明确导入公开知识范围。
