## 当前可用行为

平台登记 41 项受控工具，按当前账号、项目、策略和功能权限过滤。正式验收账号发现 40 项，联网能力仍受会话开关限制；能力目录不授予对象访问权限。

- 个人工程使用真实 `updatedAt` 和来源版本；过期修改与导出拒绝执行。工程更新不改变原始资料或资料默认配色。
- 导出复用原地理任务队列，执行、完成、状态和下载重新校验授权。相同请求复用真实任务，文件就绪后对话自动续接；取消到保存点结束，已完成成果不因取消删除。
- 本人科研任务可查询、暂停、继续和停止。控制修订防止覆盖较新的用户决定，业务流记录 `actor=agent`，等待人工批准的任务仍停在原批准节点。
- CSV 导入只接受本人本轮明确附带的文件，最多 5 MiB、5000 行和 200 列；确认后新建独立私有表，不接收服务器路径、不覆盖旧表。其他格式使用标准导入页面。
- 发布明确本人文件或专题图的具体版本与角色范围；分享仅发送单个对象的只读邀请，接收人仍须接受。双方的项目、功能和底层资料权限实时核对。
- 操作预览绑定用户、项目、运行、对象、修订、范围和 15 分钟有效期。模型没有确认工具，`confirmed=true` 不构成批准；并发确认只认领一次。执行结果不明时保留待核对状态，不盲目重复创建外部表。

智能体顶部新增“平台操作”，可按轮次查看待确认操作、分页调用回执和能力说明；产生预览的回复也提供入口。面板展示对象、范围、版本、期限及真实结果，区分已导入、已发布和邀请已发出。账号、项目或会话改变后，旧内容与旧界面请求会清除。
