# 数据分析通用化（v0.1.22）

数据分析入口保留 `/nongeo` 路由，界面统一称为数据分析。资源列表展示当前项目内有权查看的数据，支持全部、地理、非地理及分类筛选。胡杨是独立示例，需要主动打开；空列表、查询权限不足或真实资源失败均不会自动替换为示例。

表格和已有专用格式继续使用现有统计接口，按返回的字段生成图表。分类维度可选，指标关系、数值分布及相关性使用通用文案，不预设物种、遗传或生活型。栅格、矢量通过地理工作台查找及计算工具入口处理；文档、图片提供资源查看和整理为结构化表格的指引。本次未新增栅格、矢量统计引擎。

API 契约、后端授权、单项目范围、文件路径和后端栅格渲染不变。版本文件和变更日志仅更新本次发布版本。

本地浏览器测试覆盖空工作区、主动示例、普通表格分类选择、空间资源分流、地理/非地理筛选、查询权限、真实资源错误以及已有直方图和散点图行为。服务器沿用隔离候选验收后切换的流程，生产验收通过后再推送相同提交。
