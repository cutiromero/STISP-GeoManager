# 普通智能体任务内交互（2026-10-16）

## 页面与状态

普通数据智能体和模型对话均可由模型提出问题卡，支持单选、多选、文字补充；用户点击确认或从输入框补充文字后，答案回到原 AgentRun。每张卡记录问题、原因、建议默认值、当前计划、提交时间和回答。默认值需要用户确认。

新增运行状态：`waiting_input`（等待回答）、`waiting_review`（等待审核）、`waiting_compute`（计算中）。等待不占模型执行槽；同会话不能绕过待处理问题新开任务。切换会话、刷新或工作进程重启后，从服务端记录恢复。

`interaction` 返回最新问题，`interactionHistory` 返回完整问题与回答历史；内部提交摘要不返回浏览器。后台保存原请求、已返回工具证据、完整模型上下文、当前计划和执行步骤。思考片段继续使用模型服务实际返回的 thinking 事件。

## 回答与并发

`POST /api/agent/runs/{id}/interaction/` 接收 action、questionId、revision、submissionKey、answers 和 text。接口检查本人、当前项目、当前能力、来源权限和问题版本；相同提交键与相同内容重复提交只返回已有状态，不重复启动。旧卡用新提交键重答返回冲突。

信息问题可直接补充文字，由模型解释更新；审核问题必须显式填写 `approval=approve|reject`。拒绝停止后续处理，通用问题卡的批准不替代地质修改方案的逐项批准。地质编辑算法保护复用科研审核登记表 `EDIT_CHECKS`。

取消等待后不会启动后续操作。取消智能体处理不会自动停止已经提交的隔离计算，界面会说明可以在计算任务卡单独停止。

## 算法与真实结果

普通对话不再先走 NDVI/NDWI 的固定快捷执行并直接结束；数据智能体由模型核对数据、算法、知识与必要参数。用户写明的参数及问题卡答案作为确认信息，后续回答中的明确修改覆盖较早选择。超出真实波段范围时返回实际波段数及矛盾参数。

旧算法参数卡继续使用签名方案、数据修订和幂等校验，点击运行后也接回原任务。当前问题涉及目标、其他条件或审核时，旧参数卡不能抢先执行。

同一任务可在读取结果、获得新回答后继续执行其他算法，或用新参数重新计算。已提交计划保存为历史；实际任务幂等键包含算法版本、输入和参数，重复同一工具调用不会重复提交。新回答会刷新尚未执行的旧参数计划。自动入库只由用户原请求、补充文字或真实选中的入库选项授权；同一次回答明确取消时采用不入库，题干中的“是否自动入库”本身不构成授权。

尚未提交的计算计划不能标为已完成。模型提前结束时，平台要求它依据实际缺项或冲突提出问题卡，或在条件齐备后提交计算，保持同一任务的继续处理。

用户在最新实际回答或选项中明确取消计算时，未提交计划取消，工具入口也阻止模型继续新建计算。用户可以结束任务，也可以改为解释等新目标。已提交任务保持原状态，可在任务卡单独停止。用户仅提供历史计算统计要求解释时，保留模型解释，不把背景中的“计算完成后”或知识中的“状态”误当成任务进度追问；长句中的状态追问需与同一分句的计算或任务语境对应。

提交计算后保存上下文并退出模型worker。计算终态返回后，平台读取真实任务和输出编号，加入证据，再只排队续接一次。模型通过 `read_compute_output` 核对实际输出文件校验和并读取结果，然后继续解释或选择工具。回答保留模型的分析正文，任务状态与已有地图、预览、下载、入库入口来自实际计算记录。

`read_compute_output` 对表格分页读取实际CSV，返回总行数和下一页；栅格复用统一 GDAL 调用读取近似数值统计，明确统计范围，不据此推断生态因果；其他格式核对文件并返回元信息与预览入口。读取过程不修改原数据。

栅格元信息区分实际计算源文件与地图显示缓存。计算输入输出的尺寸、波段和坐标系以源文件读取结果为准；源文件不可读时保持未知。Byte等存储类型不等同于原始DN或定标结论，源与显示规格差异也不能直接解释为算法进行了投影或重采样。

普通模型对话只开放问题卡，不能使用数据、计算和知识平台工具。原有纯文本模型响应仍能作为正文显示。
