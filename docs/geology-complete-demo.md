# 地质检查与海德乌拉演示

## 现有设计与本轮补齐

| 原设计意图 | 核对结论与实现范围 |
| --- | --- |
| 岩性、构造、矿物检查 | 已有真实检查、逐项批准、修正与复核。原正式案例只覆盖代号、构造不参与和矿物降权六项操作。 |
| 地图内容变化 | 新增同单元融合代表案例。以项目整理规则、共享线、分类一致及构造距离为条件，批准后移除冗余内部边界。 |
| 处理前后远景区 | 沿用相同参数真实计算，保留逐区依据；权重参与组合，降权与删除分别处理。 |
| 地层接触与共生 | 分规则评价候选识别；另对共享线位置及类别配对作独立评价。规则分组不等于完整专业关系判断。 |
| 构造关系 | 实际重建处理前后几何相交和推测交汇；独立控制区分沿界、点接触与穿越两侧内部。完整切割年代解释仍需专门资料。 |
| 分级处置 | 保留、降权、待裁定、暂不参与分别保存；模型提出建议，人工批准后仅执行选中范围。 |
| 来源与试用状态 | 原17条保留试用修订，新增L-05明确为项目整理规则；每处可展开知识、测量、批准与算法记录。 |
| 独立评价 | 独立随机样例、标定集与测试集分开，阈值先冻结；测试资料只用于验收，不进入正常算法或模型输入。 |

L-03检查名称与代号一致性；它不代表地层接触、切割时序和共生关系全部经过验证。小面积、时代排序或单条规则命中用于发现疑点，修改仍需满足具体条件。

## 两个案例

原地质成果检查案例保留70.56平方公里范围和五处问题：三处内部漏填、两处时代属性问题。原任务、原始资源、报告与历史比较入口保留。

海德乌拉完整演示在原六处讲解基础上增加真实融合。原541个岩性面没有符合新条件的同类别共享线对象，因而另保存明确标注的演示整理副本。该副本有542个岩性面；正常运行输入保留中性对象编号，不含准备映射或正确答案。独立验收参考另存。

新增规则要求同一地质单元粒度、名称代号和已有分类字段一致、实际共享线、无有效内部细分资料、共享边界远离构造。用户批准的对象与承接对象一起构成修改范围。涉及对象面积、移除边界长度分别统计；外部覆盖面积和同类面积保持。

岩性和构造资料属于演示模拟，矿物输入为遥感识别成果。知识支持检查与解释，不能把本示范区结果直接解释为野外验证或找矿准确率。

## 直接演示

1. 进入逻辑推理项目，在成果展示选择地质检查或海德乌拉；也可进入智能体的MH-workflow选择相应场景。
2. 使用预设资料生成计划并执行。观察真实检查、知识引用、代表疑点和建议。展开来源查看具体规则与适用条件。
3. 在审核卡勾选建议并批准，或拒绝。拒绝保持原图；修改方案后再次确认。等待期间可以刷新，继续原任务。
4. 完成后查看独立结果讲解页。海德乌拉依次展示总览、岩性、构造、矿物、调查建议；上一处、下一处定位实际对象。
5. 每处对照“发现了什么、哪条知识支持、算法实际做了什么”。代号直接显示文字，构造用原线与灰色虚线表示分析状态，矿物展示实际权重。
6. 点击“在地理工作台对比”。同一组包含改前、改后及橙色修改高亮，可切换单图和同步双图，查看全部或当前修改。重复进入复用原图层，刷新恢复选择与视角。
7. 在最终文件区预览、下载报告、统计与地图，按已有权限入库。独立评价默认折叠，单独展开查看，评价文件不成为智能体资料。

## 讲解时可以这样说

“先让系统读地图，再查专家知识，找出需要复核的地方。每条建议都能看到对应的知识和测量。我们批准部分建议，其他对象保持原样。”

“这里不仅改了代号，还按本案例的整理条件融合相邻分块。构造原记录仍保留，只改变本轮是否参与分析；矿物证据降低权重后继续参与计算。”

“最后重新计算交汇关系与核查区。地图、数量和面积都来自本次任务，调查建议的变化也能定位。独立评价告诉我们哪些检查可靠、哪些还需要补资料。”

## 验证与追溯

本机算法测试、真实worker试运行、独立模拟评价、服务器真实模型与页面验收分别记录。部署回执和任务证据保存在运行目录，不把未完成的服务器步骤记为通过。

独立评价目前覆盖17条原规则、按单元标签汇总的实际线接触、构造全部异常与覆盖子集，以及小型几何控制。标定目标未全部满足，L-02等仍有误报；这类结果用于人工复核。矿物缺少独立真值，只报告规则命中和真实处理影响。

独立评价接口绑定工作流、输入快照和实际算法版本，提供受控预览与下载。内部参考、准备清单和随机标签不注册为普通资源，也不提供给模型、知识检索或编辑算法。
