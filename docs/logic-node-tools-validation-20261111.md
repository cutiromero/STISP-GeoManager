# 逻辑推理节点执行与思考设置验收

代码基线为 `bccd8d2`，开发分支为 `codex/xintao`。验收使用独立测试数据库、临时存储、模型协议桩和仓库真实地质计算内核。

## 思考设置

| 调用位置 | 有效行为 |
| --- | --- |
| 目录启动 | 默认标准 `medium`，轻量 `low`、深度 `xhigh`；三档均开启思考，并保存到真实父运行 |
| 会话发起业务流 | 继承同一用户、项目、会话绑定运行的模式、显式强度与任务预算 |
| 资料用途建议 | 启动面板的强度传入角色识别；角色识别及协议修正保持相同设置 |
| 字段建议与阶段规划 | 使用任务绑定设置，规划不覆盖为轻量 |
| 节点执行、独立审核与返修 | 从父运行解析设置；逐角色核对实际模型能力，分词、生成和审计一致 |
| 上下文归纳 | 保持本次任务思考设置，缓存身份包含模式及强度 |
| 最终分析与报告重新解读 | 保持任务设置，真实模型根据已读取统计、批准范围及证据形成文字结论 |

新建后台策略默认 `medium`；已保存管理员策略和明确选择继续有效。审核模型不支持所选思考模式时明确拒绝，不能静默关闭思考。HTTP捕获检查模型生成与tokenizer的 `chat_template_kwargs` 完全一致；思考模式不使用会抑制Qwen思考流的JSON约束解码，响应仍严格按原协议校验。

## 算子清单与科学约束

源码中的四个核心包均采用第2版语义清单，包含输入语义角色、字段映射、参数范围与Agent建议、输出说明、错误补救、资源说明及自检。

| 算子 | 当前源码版本 | 用途 |
| --- | --- | --- |
| geology-multi-check | 1.4.1 | 初检与修正后复查 |
| geology-multi-apply | 1.4.1 | 执行实际批准的处置 |
| geology-multi-relations | 1.3.1 | 构造关系重建 |
| geology-multi-prospect | 2.4.1 | 远景区与依据链 |

新任务在五个计算阶段使用共享 `node_loop`：查询目录、选择已确认登记版本、绑定输入、填写允许参数、预检、计算、核验真实统计并交付。大型地质清单完整保存在节点证据中，按UTF-8字节片段读取，目录截短不丢失真实端口契约。节点失败保留诊断，模型可据此修正映射并重新预检；同一错误不重复尝试同类补救。

科学配方在资料确认后冻结。节点不能自行更换未确认版本、修改阈值或网格、交换输入来源、扩大处置对象。字段映射只能重申已确认的工作副本语义。涉及这些改变时等待用户重新确认，平台故障与不可恢复失败停止自动重试。预检签名覆盖版本、全部输入、参数和字段映射，计算方案必须完全匹配；提交前在事务中重新核对专业计划、资料、算法、权限和控制状态。

修正输入沿用原服务根据实际批准生成的修改表。人工决定、结果质量复核、真实成果入库和下游绑定保持原边界。模型提前结束节点不能代替真实计算成功。旧任务和显式关闭Agent的专业任务使用原执行器；已发布算法包与科学内核保持原内容。

## 七节点与科学对照

正常路径与故障恢复路径均对照原专业执行器，使用相同合成地质资料、同一组规则、相同参数和相同建议批准方式，实际调用地质计算内核。

| 场景 | 节点工具生成请求 | 科学结果 |
| --- | ---: | --- |
| 正常目录、预检、计算、交付 | 20 | 七节点完成，报告生成成功 |
| 初检预检故意使用错误映射，依据诊断纠正后重新预检 | 21 | 七节点完成，1次有限补救，报告生成成功 |

每组对照检查18份表格、8份矢量和11份栅格。表格全部记录与字段一致；矢量属性、CRS和几何一致，几何比较容差为微米级；栅格像元、有效掩膜、CRS、变换与NoData一致。原始样例输入校验和保持一致。统计和科学文件参加对照，报告文字不参加科学一致性比较。

测试覆盖本地小型样例。生产资料中历史的8个远景区与约79.26平方公里属于既有验收证据，仍需在新环境使用同一资料、版本、参数和批准范围复验。协议桩与HTTP捕获证明设置传递正确，真实模型的思考输出、耗时、协议稳定性和文字质量需要实际模型联调。

## 接口与界面

`BusinessFlowStart.reasoningEffort` 接受 `low / medium / xhigh`，默认 `medium`。资料用途建议接口接受相同可选字段。非法值返回400；显式要求不受支持的思考模式返回403；同一幂等键不同设置不能复用旧任务。

业务流启动面板提供轻量、标准、深度选择，默认标准；聊天入口与启动面板的设置同步。原专业字段、处置、质量审核界面继续承载相应决定。节点进度、模型审计、工具历史及恢复问题沿用已有业务流展示。

本节验收资料仅存在于测试数据库及临时目录，无生产科研记录。部署与真实模型联调由独立发布回执记录。
