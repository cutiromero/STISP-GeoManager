# 普通智能体原任务交互

## 页面操作

进入“智能体 → 数据智能体”，按原方式选择自动或手动的数据、算法和知识分区。参数和授权明确时模型继续处理；缺少下一步必需信息时，在当前对话提出问题卡。模型对话也能提出澄清卡，保持原来的平台访问权限。

问题卡说明要确认什么、为什么需要，并提供单选、多选或文字输入。默认选项只预填，点击“确认并继续”才提交。输入类问题也可以直接在下方聊天输入框补充，回答回到原任务。审核需在卡片中明确选择批准或拒绝。

等待期间左侧与对话区显示“等待您回答”或“等待您审核”，不占用模型执行槽。刷新、切换页面后从服务端恢复同一问题、实际工具证据和回答。相同提交键不会重复计算；问题或方案变化后旧卡返回冲突，按新卡操作。取消等待后停止后续动作并保留记录。

模型结合补充条件重新判断，继续使用已授权的平台数据、算法和知识工具。算法完成后读取实际输出，再形成解释。结果沿用现有任务卡：查看地图、预览、下载与入库。停止智能体后，已提交计算可在任务卡单独停止。

## 机制与边界

- `ask_user` 由模型决定询问内容，服务端验证结构和权限；没有固定NDVI问答脚本。
- 保存原消息、真实工具返回、当前问题、回答和计算关联，回答后继续原 `AgentRun`。
- 用户明确给定的有效自定义波段会被接受；实际波段数不足等矛盾才要求纠正。
- 通用审核卡不代替地质修改的逐项批准；编辑算法仍须通过原方案审批。
- 模型思考仅保存服务实际返回片段；可核对的工具记录、用户回答和结果说明独立保存。
- 栅格输出的GDAL近似统计用于说明数值分布；生态原因结合知识适用条件和实际辅助证据判断。

API与迁移见 [开发说明](developer-guide.md)。清理历史结果见 [计算结果清理](computation-result-cleanup-20261016.md)，新增生态资料见 [生态知识接入](ecology-knowledge-ingestion-20261016.md)。

## 验证口径

本机自动化使用隔离数据和模型替身核对状态机、回答幂等、权限、真实文件读取和浏览器表单行为。真实模型验收另记录实际会话、工具返回、计算任务、输出校验和、知识引用与恢复结果；候选和正式发布以同一提交的私有回执为准。

可复制的体验提示词（先在数据按钮选择一张实际多波段影像）：

1. “用平台NDVI算法处理选中的影像。先检查真实波段信息；缺少必要条件时在本任务里问我，确认后计算，先预览，不自动入库。”
2. “用选中影像计算NDVI，红光第3波段、近红外第8波段。请核对波段范围，条件满足就运行；完成后读取实际结果并解释，先不要入库。”
3. “结合本项目专家知识解释NDVI下降：目前只有两期NDVI，没有地下水、降雨和树龄记录。先说明能判断什么；如果必须补充信息，请给我选项，并按我的回答继续。”
