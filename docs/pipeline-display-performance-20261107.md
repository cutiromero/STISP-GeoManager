# 2026-11-07 原站管线显示优化

背景：第一轮按视野加载后，全球两类管线仍有1394460个顶点。真实服务端基准：天然气3318条/580494点/16.08MB JSON，石油1405条/813966点/19.12MB JSON，全球查询分别7.56和9.29秒；中哈区域查询0.26和0.10秒。只限制要素数量不足以限制顶点和响应体积。

本次仍更新现有/map及既有查询接口。先以契约角色更新OpenAPI、开发指南、mock及生成客户端，随后交接后端实现显式lineSimplifyTolerance、空间缓存及gzip，最后交接前端接入按视野尺度的线显示。单代理依次承担角色，无并行修改。

普通大线图层最多显示10000条并受系统查询上限约束，替代600条预算；点1500、面600维持。按视野较窄轴的约半像素（1024px基准）选择二进制容差档，最大0.05度，细于1e-5度时停止简化。点和面不参与线简化。省略新参数保持现有量化语义，显式查询不启用新参数。所有筛选、统计和返回范围仍基于原始几何；显示端点和属性保留，不裁剪或写回原数据。简化线不保证不同要素之间网络拓扑不变，不用于精确量测、编辑、计算和导出。

服务器按完整请求和资源修订缓存空间显示结果，每资源最多32条，属性过滤不缓存；缓存入口沿用权限校验。查询接口协商gzip，精确客户端解压后语义不变。缓存版本3使旧缓存失效。项目授权、owner_only、数据路径、栅格渲染及数据库结构均不变；不创建测试业务资源。

部署必须冻结新SHA/发布包，使用新候选目录和隔离配置，验证后备份切换HTTP，实际公网复验。测量结果另存发布回执，不将上面的旧基准当作新优化效果。

显式线简化预览对原始坐标做完整的向量化范围校验，跳过逐顶点小数位不确定度估算；默认查询保留原精度估算。

图层导出前根据视野查询键重新请求相同范围与上限的原始几何，不携带显示参数，再提交原有导出接口；屏幕预览保持不变。

部署准备期间现网切换至9720254-input-reuse。已将该版本相对4de5d49的真实源码差异取回独立快照，先合并其计算输入复用、人工核查和对应契约，再重新生成客户端并复验本次58项后端、9项前端单元和8项浏览器测试。正式候选以该现用目录为基线，不回退其他已上线改动。

公网整轮刷新仍存在三个图层串行等待，随后将视野请求调整为线图层优先、最多两路并行，使用后端既有两个显示查询槽；移动或切换项目统一取消两路旧请求。新增浏览器测试验证两条管线先启动、第三层在一个槽释放后启动、卸载取消全部在途请求。
