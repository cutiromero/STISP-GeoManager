# 原站管线瓦片和灾害点聚合

目标：原站普通无筛选地图显示使用预生成MVT，管线按瓦片切分和分级简化，灾害点全量按WebMercator网格聚合。初始范围仍为用户当前视野。原始GeoPackage不修改，精确查询、属性表和导出按原始数据读取；栅格行为不变。

单代理按契约→后端→前端角色顺序交接。契约API-20261107-004先定义profile.vectorTiles及授权瓦片读取；后端离线管理命令准备缓存，HTTP只读取。前端仅普通无筛选资源使用已就绪瓦片；有筛选的查询仍为GeoJSON业务结果，不从瓦片还原。

缓存位于TOML业务数据根cache/vector-tiles/v1/project/resource/revision；版本包含资源更新时间、项目、GeoPackage路径和图层。生成时SQLite只读一致性快照，暂存目录完成后原子发布，源修订变化则拒绝发布。每请求按query_data、load_vector_layer、项目及owner_only鉴权，再处理ETag。客户端private,no-cache，不能共享公开缓存。

MVT由统一GDAL CLI封装生成0～10级；管线保留属性和原FID，简化与裁剪仅用于显示。点按每级固定64像素网格聚合，单点保留原属性，多个点显示point_count、point_count_abbreviated，点击聚合放大；10级展开原始点。聚合不代表空间查询结果。瓦片WebMercator纬度限制±85.051129度，精确业务仍读取原始坐标。不同管线的网络拓扑不可由显示瓦片判断。

前端同步支持vector source-layer、跨瓦片稳定要素状态、显隐/排序/样式、点击属性、工程恢复；属性表按需查询当前范围原数据；导出查询相同当前范围原始几何及既有系统上限，不导出聚合节点或瓦片片段。

验证计划：本机契约/类型/构建、前后端缓存鉴权和聚合数量测试；隔离服务器真实GDAL生成、瓦片解码及区域查询一致性；候选浏览器三图层/聚合展开/显隐/属性表/导出/工程恢复；冻结SHA→备份HTTP切换→真实公网同范围复验。回执分别记录准备耗时、首屏静态加载、瓦片加载和整轮完成，不承诺固定秒开。

本机验证（2026-11-07）：后端80项及3个子测试、前端559项、浏览器hook/精确导出12项通过；类型、改动文件lint/format、OpenAPI生成一致性/变更交接/文档/Prism及正式static base构建通过。OpenAPI存在6项既有未使用schema警告。真实MVT及上线状态必须以pipeline-tiles发布回执补充，不以mock生成器代替。
